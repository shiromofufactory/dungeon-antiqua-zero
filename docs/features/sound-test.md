# サウンドテスト

## 目的と起動

BGMをループ再生しながら、Pyxel SEとWAV SEの音量バランスを比較する制作ツール。
`npm run sound-test`、または `python3 -B -m tools.sound_test` で起動する。

本番と同じ `app/assets.pyxres`、`app/audio` のOGG、`app/se` のWAV、
`app/audio/catalog.json` を読み、音声の解析・再生・音量適用は本番のPlayerへ委譲する。
ゲームのSceneや画像素材は必要としない。音量係数は [効果音](./sound-effects.md) を参照する。

## 選択と再生

- 560×360px・60fpsのPyxel画面。左列がBGM、右列がSEで、それぞれ10行表示する。
- BGMは `app/audio` 内のOGGを本番のBGM IDで表示する。起動時は無音。
  BGM再生で選択曲を必ずループ再生し、停止で止める。再生中に別の曲を選ぶと即時切り替える。
- SEはPyxel／WAVの2種類を切り替える。種類ごとに選択位置を保持する。
- Pyxel SEは0〜63を必ず表示する。現在のカタログで同じSound番号を参照するSE IDを
  `7 (alert)` の形式で表示し、複数あれば名前順に併記する。未登録番号も選択・再生できる。
  WAVへ差し替え済みのIDは、以前のPyxel Sound番号には関連付けない。
- WAVは `app/se` 内のファイルをサブフォルダも含めて列挙する。カタログ未登録でも試聴できる。
  拡張子は大文字・小文字を問わず、隠しファイルとフォルダ外へのリンクを除外する。
  相対パスの大文字・小文字を保ち、大文字・小文字を無視した名前順に並べる。
- SE再生で選択音を1回再生する。再度押すと再生中のSEを置き換える。SE停止はBGMを止めない。
- リストの選択ではSEを鳴らさない。長い名前は一覧内に収め、選択中のSEの全名を下部にも表示する。
- BGM・WAVの候補とカタログは起動時に読む。素材追加・カタログ変更後はツールを再起動する。

## 音量と操作

BGM・SEそれぞれの音量を0〜4のボタンで変更でき、再生中にも即時適用する。
初期値は `Settings` の初期値と同じ。設定ファイル、カタログ、音声素材には保存しない。
ゲーム用の音量係数を持つ `BgmPlayer` と `SoundEffectPlayer` を使用するため、
呪文エフェクトエディタの補正なし試聴とは異なり、本番の音量バランスで比較できる。

マウスは候補・音量・種類・再生／停止ボタンをクリックする。
リスト上でホイールを動かすと3項目ずつ選択を進める。

| キー | 動作 |
| --- | --- |
| Tab | 操作するリストを切り替え |
| ↑／↓ | 選択を1項目移動 |
| PageUp／PageDown | 選択を10項目移動 |
| ←／→ | SEリストの操作中にPyxel／WAVを切り替え |
| Space | BGM再生／停止 |
| Enter | SE再生 |
| Q／Esc | 両方の再生を止めて終了 |

選択はリストの端で停止し、循環しない。選択位置が見えるようにリストをスクロールする。
ファイルがない場合は空リストを表示する。再生対象の欠落やデコード失敗は画面下へエラー表示し、
別の音源には置き換えない。エラー後も選択や再生操作を続けられる。

## 検証

`python3 -B -m unittest tests.test_sound_test tests.test_audio_resources` で、0〜63の候補、
カタログ名の併記、未登録WAV、空リスト、BGMループと曲切替、両音源の共通SEチャンネル、
独立した音量変更、停止、範囲端、読込失敗、リスト操作を検証する。
Pyxel画面は実起動して目視確認する。初期画面の画像保存には
`npm run sound-test -- --screenshot /tmp/da0-sound-test.png` を使用できる。
