# 攻撃ポーズ調整ツール

## 目的

戦闘シーンの攻撃アニメーションを実装する前に、キャラクターの静止ポーズと武器画像を
1px単位で重ね合わせ、攻撃アニメーションのキーポーズとして保存するローカル制作ツールとする。
本ツールは画像素材そのものを変更しない。

## 起動

リポジトリルートで `npm run attack-pose-editor` を実行する。ローカルサーバーが起動し、
ブラウザで編集画面を開く。

## 画面

画面は左のキャラペイン、中央のメインペイン、右側の武器ペインと保存ポーズペインで構成する。
中央は8倍表示のキャンバスが収まる幅を基準とし、右側は中央より広く確保する。武器ペインと
保存ポーズペインは右側で横に並べ、上下に積んだ場合のペイン内スクロールを避ける。
保存ポーズの `weapon_img` と枝番は2列に並べ、編集欄の縦幅も抑える。
保存ポーズペインは表示領域の高さに収め、ポーズ一覧だけを内部スクロールする。
新規作成、複製、削除とID編集欄は一覧をスクロールしても表示したままにする。

- キャラペインは `content/images/characters/ch_battle.gif` を参照する。フィオラ、エリカ、
  ダイン、アルファード、ライザを切り替え、各キャラクターの横16px単位のポーズ0〜8を選択する。
  横位置9の死亡ポーズは表示しない。キャラクター選択は確認表示にだけ使い、保存しない。
- 武器ペインは `app/assets.pyxres` のイメージバンク0、`(0, 32)` から
  `(255, 47)` までを16×16px単位で分け、画像番号0〜15として選択する。選択した武器は
  左右反転と上下反転をそれぞれ独立して切り替えられる。武器2を追加すると、2種類の画像を
  同時に配置できる。位置、反転、キャラクターとの前後関係は武器ごとに設定する。
- メインペインは64×64pxの論理キャンバスを8倍に拡大表示する。キャラクターは座標基準点へ
  固定し、武器座標だけを基準点からの相対座標として保存する。画面上の基準点はドラッグ、
  矢印キー、数値入力で移動できるが、見やすい位置へ表示を移すためのビュー状態であり保存しない。
  武器も同じ操作で1px単位に移動する。
- コンポジット欄には選択中の保存ポーズに対する種族別の武器Y補正を表示する。
  補正値はフォームへの整数入力だけで変更し、武器1・武器2の両方に加算する。
  キャラクターを切り替えると、その種族の値でプレビューする。同じ種族のキャラクターは同じ値を使う。
- 保存ポーズペインは画面右側に置き、ポーズの切り替え、新規作成、複製、削除、
  `weapon_img` と枝番の変更を行う。
  各ポーズのハンドルをドラッグ＆ドロップすると、挿入位置を表示しながら任意の順序へ並び替える。
  並び替えた配列順をそのままJSONへ保存する。
- 保存ポーズには `content/data/items.json` で使用中の空でない `weapon_img` を選択し、任意の
  枝番を入力する。ポーズIDは `<weapon_img>_<枝番>` として自動生成し、直接編集しない。

## 保存データ

正本は `content/battle/attack_poses.json` とする。初回保存時に作成し、複数のポーズを1ファイルで
管理する。IDはアイテム側の `weapon_img` と制作者が指定する枝番から生成した安定キーとする。
ゲーム用生成物はエディタ保存時に `app/effects/attack_poses.json` へ出力する。
`npm run attack-poses:build` でも再生成でき、通常ゲームと戦闘モックの起動時にも自動生成する。
ゲーム側は正本を直接読まない。起動中の戦闘は読み込み済みの定義を使い、次の戦闘から新しい設定を使う。

```json
{
  "format_version": 1,
  "poses": [
    {
      "id": "SWORD-1_1",
      "weapon_img": "SWORD-1",
      "branch": "1",
      "character_pose": 0,
      "race_y_offsets": {"FAIRY": -3, "HUMAN": 0},
      "weapons": [
        {
          "image": 0,
          "position": [0, 0],
          "layer": "front",
          "flip_x": false,
          "flip_y": false
        }
      ]
    }
  ]
}
```

`weapons` は1件以上2件以下とする。各武器の `position` はキャラクターの座標基準点からの
`[x, y]` 相対座標、`layer` は `front` または `back` とする。`flip_x` は左右反転、`flip_y` は
上下反転を表すbooleanとする。キャラクター座標と画面上の基準点は保存しない。同じlayerに
武器が2つある場合は、武器1、武器2の順に描画して武器2を手前にする。
`race_y_offsets` はポーズごとの種族キーと武器Y座標への加算値で、-128〜128の整数とする。
省略した種族および旧データでフィールド自体がない場合は0とする。キャラクター側の表示Y座標は
変更せず、武器の表示Y座標にだけ加算する。投擲武器の飛翔開始位置にも同じ補正を適用する。

`weapon_img` は `items.json` の空でない同名フィールドから選ぶ。`branch` は英数字、ハイフン、
アンダースコアからなる枝番とし、`id` は常に `weapon_img + "_" + branch` と一致させる。
同じ `weapon_img` に複数ポーズを割り当てる場合は、`1`、`2` など異なる枝番を使用する。

## 受け入れ条件

- 5人のキャラクターと、死亡を除く9ポーズを選択できる。
- 武器帯の16個の画像枠を選択できる。素材上の空枠も番号を維持して表示する。
- キャラクターは基準点へ固定され、保存データにキャラクター座標を持たない。
- 画面上の基準点を移動しても保存状態は変更されない。
- 武器を最大2つ重ね、各武器を1px単位で移動し、前後関係と左右・上下反転を切り替えられる。
- 種族別Y補正を入力すると、同じ種族のキャラクター全員の両武器に反映され、保存・再読込後も維持される。
- ポーズを新規作成、複製、削除、切り替えできる。
- 保存ポーズをドラッグ＆ドロップで並び替え、再起動後も順序を維持できる。
- `weapon_img` と枝番から重複しないポーズIDが自動生成され、アイテムデータと対応付けられる。
- 不正なポーズ番号、画像番号、座標、重複IDを保存しない。
- 保存したJSONを再起動時に復元できる。
