# ゲームメニュー（強制割り込み）

## 操作と表示

- DA2のEsc／ゲームパッドStartによる割り込みを移植する。DA2と同じくGuideボタンも
  同じ入力とする。Escは通常キャンセルではなく独立した割り込み入力として扱い、
  通常キャンセルはX／Backspace／B、フィールドメニューはS／Tab／X・Yボタンのままとする。
- タイトル、スタート・ロード、フィールド、会話、ショップ、各メニュー、戦闘と戦闘結果画面で開ける。
  フェード、エンカウント演出、戦闘開始・逃走・結果切替、戦闘からの復帰、
  タイトル画面へ戻る処理の途中では受け付けず、入力も予約しない。
- 黒背景に透明Window `(0, 22, 64, 16)` を即時表示し、枠とWindow背景は描画しない。文言キーは上から
  `game_menu.resume`、`settings.return_title`、`settings.quit` とする。
  現在の設定言語を使用し、初期カーソルは先頭に置く。言語別フォントによる最長項目の実描画幅を
  測り、文字ブロック全体を画面幅256pxの中央へ配置する。各項目は同じ左端から左揃えで表示する。
  4pxグリッドの端数は水平ピクセル補正で扱う。
  Y=2／5／8の12px行間とし、カーソルも同じY座標に置く。カーソルは各項目の
  文字開始グリッドから左へ3グリッドに置く。
  後ろ2項目は `NEGATIVE_COLOR` とする。
- 上下で選択、決定で実行する。通常キャンセル、Esc、Start、Guideでは再開する。
  DA2と同じくタイトル復帰と終了は追加確認なしで実行する。

## 停止と復帰

- 割り込み中は元画面の更新・描画、移動、会話進行、戦闘処理、演出タイマー、
  アラート更新、プレイ時間の計上を止める。元Scene／Overlayやカーソルを作り直さない。
- BGMは再生位置を保存して停止し、再開時は同じ音源、位置、ループ設定、音量から続ける。
  ワンショット後の予約BGMも保持する。既に鳴っているSEはDA2と同じく停止・巻き戻ししない。
- 開いた直後は決定・キャンセル・割り込み入力が離されるまでメニュー操作を受け付けない。
  閉じたフレームの入力を元画面に渡さず、すべてのアクション入力が離されてからBGMと
  元画面の更新を再開する。方向入力だけの押しっぱなしは復帰を妨げない。
- タイトル復帰はアクション入力の解放後、既存の端末設定を保持した復帰処理を利用する。
  起動モードも保持して仮タイトルへ戻る。未保存のゲーム進行は破棄するが、
  セーブスロットは変更しない。画面倍率の変更がある場合だけPyxelウィンドウを再初期化する。

## 受け入れ条件

- 枠・Window背景を表示せず、3言語とも文字ブロック全体が画面幅の中央にあり、各項目の左端がそろう。
- Esc／Startで通常キャンセルやフィールドメニューを同時に発火させない。
- 戦闘、会話、ショップ、各メニューから開き、更新を止め、同じ画面・状態へ復帰できる。
- 開閉時の同時押し・押しっぱなしで元画面の決定やキャンセルを実行しない。
- 各種遷移中の入力では割り込まず、遷移後に自動で開かない。
- BGMの再生位置とワンショット後の予約を保持できる。
- タイトル復帰と終了を実行でき、既存の設定・セーブスロットを保持する。

回帰検証は `python3 -B -m unittest tests.test_game_menu tests.test_input tests.test_audio_resources`
で実行する。
