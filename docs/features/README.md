# 機能仕様書

## このディレクトリの目的

`docs/features/` は、ゲーム本体の機能ごとの操作、画面表示、状態遷移、例外条件、
受け入れ条件を管理する。プログラマーとゲームデザイナーが実装・確認に使う詳細仕様であり、
イラスト、PVなどの制作スタッフ向けポータルには掲載しない。

文書の責務は次のように分ける。

- `content/docs/da0.md`: 世界観、シナリオ、ゲーム体験、主要なゲームルール
- `docs/features/*.md`: 機能単位の詳細な振る舞いとUI仕様
- `docs/program-architecture.md`: 責務分割、依存関係、状態の所有者
- `content/data/texts.json`: 実際に表示する文言
- `content/data/*.json`: キャラクターや商品などのマスターデータ

機能仕様書では、表示文言やマスターデータを原則として複製しない。文言は `text_key`、
データは安定キーと参照元を記載し、内容の正本へ誘導する。

## 記載基準

次の情報は機能仕様書へ置く。

- 画面やWindowの座標、寸法、表示件数
- 入力と状態遷移、キャンセル時の復帰先
- カーソル、アイコン、表示条件などのUI挙動
- 前作との差分とモック固有の確認動線
- 境界値、警告条件、受け入れ条件

複数行のメッセージ・説明本文は、特別な指定がない限りメッセージ欄・会話ログと同じ
行間（日本語・簡体字中国語は16px、英語は12px）を使う。表示を広げるための空行は
明示的に指定された場合だけ挿入し、依頼文の段落や空行をそのまま画面の行間へ反映しない。

実装クラスの責務や依存方向を変更する判断は `program-architecture.md` にも反映する。
ゲーム体験そのものを変更する判断は `da0.md` の簡潔な記述も更新する。
