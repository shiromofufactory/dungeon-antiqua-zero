# 効果音

## 定義と素材

ゲームと制作ツールは、安定したSE IDから `app/audio/catalog.json` を参照する。
カタログの `format_version` は2とし、各IDには次のいずれか一方を指定する。

```json
{
  "format_version": 2,
  "sound_effects": {
    "equip_complete": {"sound": 6},
    "spell_healing1": {"wav": "Healing1.wav"}
  }
}
```

- `sound`: `app/assets.pyxres` 内のPyxel Sound番号。0以上の整数。
- `wav`: `app/se` を起点とするWAVの相対パス。ファイル名の大文字・小文字を維持する。
- `channel` は定義しない。`sound` と `wav` の両方、絶対パス、親ディレクトリ参照、
  存在しないWAVは検証エラーとする。

配置済みの `fire1.wav`、`Slow.wav`、`Poison1.wav`、`Healing1.wav` は、それぞれ
`spell_fire1`、`spell_slow`、`spell_poison1`、`spell_healing1` へ割り当てる。
WAVはゲーム用素材として直接読み込み、BGMのOGG変換処理へ含めない。
SE IDは呪文エフェクトとイベントから引き続き参照し、音源の切替時に参照側を書き換えない。
再生元や再生状態はセーブデータへ保存しない。

## 再生と音量

- WAVとPyxel Soundは、共通のSEチャンネル0で非ループ再生する。
- 新しいSEは再生中のSEを置き換える。同時再生用のチャンネル割り当ては行わない。
- BGMは専用チャンネル2を使い、SEの再生・音量変更で中断しない。
- ゲームのSE音量は既存の `Settings.se_volume` に従い、チャンネル0のゲインへ適用する。
  WAVのみ基準ゲインの1.5倍とし、Pyxel Soundへ切り替えた際は基準ゲインへ戻す。
  音量0はどちらも無音のままとする。エディタの試聴にはこの補正を適用しない。
  倍率は `app/resources/audio.py` の `WAV_SE_VOLUME_MULTIPLIER` で調整できる。
  `1.0`が補正なし、`1.5`が50%増、`2.0`が2倍となり、変更はゲームの再起動後に反映する。
- WAVは独立した `pyxel.Sound()` に `pcm()` で読み込み、Pyxel Sound番号を上書きしない。
  ゲームと呪文エフェクトエディタ、戦闘確認ツールの起動時に登録済みWAVを先読みし、
  再生時には同じデコード済みSoundを再利用する。描画中に読込・再生を行わない。
- エディタのWAV試聴では、ファイルの更新日時またはサイズが変わった場合に読み直す。
  欠落やデコード失敗はエラーとして表示し、無音や別音源へ暗黙に置き換えない。
- 毒の歩行音は共通SEチャンネルが空いているときだけ開始する。
  全滅復帰は、復帰SEが終わってからフェードインへ進む。

## 制作ツールと検証

呪文エフェクトエディタでは、既存SEの選択・試聴に加え、Pyxel Sound番号または
`app/se` 内のWAVから新しいSE IDを登録し、既存IDの音源も変更できる。操作の詳細は
[呪文エフェクト設定ツール](./spell-effect-editor.md#効果音)を参照する。
イベントエディタは同じカタログのSE ID一覧を使用する。

カタログの解析・参照検証は `app/audio_catalog.py` のPyxel非依存処理を、ゲーム、
呪文エフェクトエディタ、呪文エフェクト生成、イベント検証で共有する。

受け入れ条件は、両音源の共通チャンネル再生、WAVの再利用、BGMチャンネルの保持、
エディタでの登録・保存・再読込、未定義ID・不正な音源指定・欠落WAVの拒否とする。
