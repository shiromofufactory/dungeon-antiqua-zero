# フィールド・メニュー仕様

## 位置付け

本書は、ワールドマップ・町・ダンジョン上のフィールド移動と、そこへ接続するメニュー・ショップ画面の
ゲーム本編仕様を定める。ワールドマップの制作形式とゲーム用生成物は
[`map-editor.md`](./map-editor.md)、画面と状態の責務分割は
[`../program-architecture.md`](../program-architecture.md)を参照する。
拠点データと訪問済み状態の正本は [`world-sites.md`](./world-sites.md) とする。
宝箱の制作データ、報酬、演出、保存規則は [`treasures.md`](./treasures.md) とする。

従来のフィールドモックとメニューモックで確定したレイアウト・UIは本編へ統合し、
以後は単独モックとして扱わない。戦闘Sceneとの接続は
[`encounters.md`](./encounters.md) に従う。現在はタイトルSceneが未実装であり、ゲームを
起動すると [`start-load.md`](./start-load.md) のロード画面を表示する。ニューゲームまたは
ロード成立後に本書のフィールドへ移る。

## 使用リソース

- マップIDは `worldmap` とし、`app/maps/worldmap.json` と `worldmap.bin` を読み込む。
- 読み込み時にformat version、寸法、チップ参照、通行行、アニメーション、atlasのSHA-256を検証する。
- 地面、オブジェクト、アニメーション、通行可否は生成済みデータだけを使い、実行時に
  `content/maps` の制作ルールを再評価しない。
- ワールドマップのプレイヤー画像はPyxelイメージバンク0の `(0, 64)` から横2列、縦4行の
  16×16px領域を使う。行は上、右、下、左、列は歩行パターン1、2の順とする。
- 町・ダンジョンのプレイヤー画像は画像ID `characters/ch_walk` を使う。先頭キャラクターの
  `battle_sprite` を8で割った商をY、余りをXとして、画像セットの起点を
  `(X * 48, Y * 128)` とする。1セットは16×32pxを横3列、縦4行に並べ、列は左足、立ち、
  右足、行は下、上、左、右の順とする。
- プレイヤー画像の透過色はパレット番号1とする。
- 宝箱は画像ID `actors/treasure` の48×16px画像を使い、16×16pxの3コマを開封状態に応じて表示する。

## 初期状態

- ニューゲームでは、256×240px、60fpsのワールドマップから開始する。
- 開始セルはワールドマップ座標 `(17, 39)` とする。
- 初期方向は下向きとする。
- 初期メンバーはフィオラ、セリオンの2名とし、2名とも前列にする。
- 装備中の初期装備を除く所持品はなし、所持金は100 Goldとする。
- ロード画面からフィールドへの切り替え成立時に、現在マップの `bgm_id` をBGMとしてループ再生する。
- マップ移動では画面のフェードアウト率に合わせてBGM音量を0まで下げ、完全暗転時に遷移先マップの
  `bgm_id` へ切り替えてから、画面のフェードイン率に合わせて設定音量まで戻す。
- 同じBGM IDなら曲位置を維持したままフェードアウト・フェードインする。

## 移動と描画

- 矢印キー、ゲームパッド方向キー、左アナログスティックの押下中方向を使用する。
- 斜め移動は行わず、入力層が選んだ上下左右いずれか1方向だけを受け取る。
- 1セルは16pxとする。world profileは1フレーム1pxで1歩を16フレーム、town／dungeon profileは
  1フレーム2pxで1歩を8フレームで完了する。
- 歩行開始後はセル境界まで進み、途中で入力を離した場合や別方向を押した場合も現在の1歩を
  完了する。次の方向はセル境界で改めて判定する。
- 行き先が通行不可またはマップ外の場合は移動しないが、キャラクターの向きは入力方向へ変える。
- ワールドマップでは移動状態にかかわらず、16フレームごとにパターン1と2を切り替える。
- 町・ダンジョンでは現在の16×16pxの足元位置から16px上へ16×32pxで描画する。停止中は
  立ちコマを表示し、移動中だけ右足、立ち、左足、立ちを各4フレームで循環する。
- カメラはキャラクターを画面中央へ追従させ、マップ外を表示しない位置で止める。
- 描画順は地面、生成済み背面オブジェクト、actorとプレイヤー、前景オブジェクトとする。
  actorとプレイヤーは足元のY座標で前後を決める。画面外のチップは描画しない。
- フェード中、メニュー中、ショップ中はフィールド移動を更新しない。
- dungeon profileで歩行を完了した後のランダムエンカウントは
  [`encounters.md`](./encounters.md) に従う。
- dungeon profileでイベントやマップ移動を発生させない通常の1歩を完了するたび、ランダム
  エンカウント判定より先に、生存中の味方全員へ装備品の `healing` 合計から毒状態の1を
  差し引いたHP増減を適用する。正ならHPを回復、負ならHPを減らし、0なら変化させない。
  毒と複数のHP減少装備は加算し、HP回復装備とは相殺する。HPは0～最大HPへ収める。
  world／town profileの歩行、イベント発火セル、マップ移動口への到着では適用しない。
- このHP減少で味方が死亡した場合は、DA2と同じ死亡メッセージを表示して次の入力を止める。
  死亡時にはすべての状態異常と戦闘中補正を解除する。戦闘参加中の生存かつ麻痺していない
  前列がいなくなった場合は、同条件を満たす並び順先頭の1人を前列へ変更し、その旨を続けて
  表示する。該当する味方がパーティ全体にいなければ全滅メッセージも表示する。6人目の控えは
  前列繰り上げ判定の対象外とする。戦闘終了時にも同じ前列繰り上げを行うが、この場合は
  戦闘中に死亡を提示済みのためフィールドメッセージを重ねない。
- 町・ダンジョンのフィールド上では、パーティ順で最初の生存かつ麻痺していない味方の
  歩行画像を使用する。該当者がいない場合だけ先頭メンバーの画像へ戻す。
- 毒状態の味方が1人以上いるダンジョン歩行中は、DA2と同じSound 43をSE ID
  `field_poison`、チャンネル3で再生し、再生終了後も歩行中なら繰り返す。HP減少装備だけでは
  この毒SEを再生しない。

## actorと宝箱

- actorは下地の通行可否と別にpartyと他actorの進入を防ぐ。人物actorの向き、自律移動、
  イベント接続は [`events.md`](./events.md) に従う。
- 停止中の決定は向いているセル、方向入力は進もうとしたセルの宝箱を通常イベントより先に調べる。
- 宝箱メッセージ中はフィールド入力を止めるが、開閉アニメーションは更新する。
- 開封済み宝箱は開いた画像の固定actorとして残り、再操作には反応しない。

## 拠点表示とマップ遷移

- ワールドマップ上では、PCから入口セルまでのマンハッタン距離が3以下の拠点名を、入口セルの
  近くへウィンドウなしで表示する。表示座標はマップとともにスクロールする。表示名は拠点の
  `name_text_key` から現在言語で取得する。ゲーム実行時は生成済みの
  `app/data/texts.json` を参照する。
- 日本語の拠点名は共通の「大きい表示文字」用途を使い、現在は
  `umplus_j12r.bdf` で表示する。他言語では同用途から各言語の
  標準フォントを選ぶ。具体的なファイル名、ベースライン補正、行高は `FontResources` に集約する。
- 拠点名は通常は入口セル群の上へ表示する。PCが入口セル群より上にいる場合は、PCとの重なりを
  避けるため入口セル群の下へ表示する。
- PCが1歩を完了して入口セルへ到着すると、フェードアウト12フレーム・フェードイン12フレームの
  暗転中に遷移先マップへ切り替え、
  指定された到着地点のセルと向きで `FieldMovement` を作り直す。
- 遷移成功時にだけ拠点IDを `SaveData.visited_site_ids` へ記録する。
- 町・ダンジョンなどからワールドマップへ切り替える完全暗転時に、味方全員の毒と麻痺を
  自動的に解除する。HPとMPは回復しない。戦闘から元のフィールドへ戻る時点では解除しない。
- 遷移先マップまたは到着地点が未作成の場合はワールドマップに留まり、訪問済みにはしない。
- 施設出口、呪文「テレポート」、テレポート装置の本編画面自体は現在の実装対象外とする。
  施設出口は移動イベントが指定する到着地点を使う。テレポートは訪問済み拠点IDに対応する
  `teleport_enabled` の到着地点を `TravelSystem` から取得し、施設出口と同じ位置・向きへ移動する。

## デバッグ機能

### テレポート

- デバッグメニューの「テレポート」には、訪問済みで `teleport_enabled` の到着地点がある拠点だけを
  マップデータ順に表示する。拠点名は現在言語の `name_text_key` から取得し、フィールド上の
  拠点名と同じ「大きい表示文字」用途のフォントで表示する。
- 候補がない場合は「いどうさきが ありません」と表示し、決定入力ではエラー通知を行う。
- 拠点を決定すると `TravelSystem` で到着地点を再検証し、拠点入場と同じ12フレームずつの
  フェードアウト・フェードインで移動する。完全暗転時に到着地点の座標・向きへ切り替え、
  デバッグメニューと設定画面を閉じてフィールドへ直接戻る。
- 移動先の検証に成功した決定時は、フェードアウト開始と同時にDA2と同じSound 8を鳴らす。
  歩行で拠点の入口セルへ入った場合のマップ移動は、従来どおり効果音を鳴らさない。
- デバッグテレポート自体では新たな拠点を訪問済みにしない。

現在の仮データでは、開始地点の「妖精の里」入口から一度外へ出て、再び入口へ歩いて入ると
`fairy_village` が訪問済みになる。その後、メインメニューの「せってい」から
「デバッグメニュー」→「テレポート」→「妖精の里」を決定すると確認できる。

### ショップ

- デバッグメニューの「ショップ」には、読み込み済みの全ショップを `shops.json` のデータ順で
  表示する。現在はショップ名データがないため、一覧には安定した `shop_key` を表示する。
- ショップを決定すると標準フェードを通して本番の `ShopOverlay` を開く。デバッグメニューで
  変更したパーティは、ショップのメンバー表示と装備判定へ反映する。
- ショップの「でる」またはメインコマンド中のキャンセルでは、デバッグメニューのショップ一覧へ
  戻る。ショップ一覧のキャンセルでは「ショップ」を選択したデバッグメイン画面へ戻る。

## 画面接続

- 論理 `menu` 入力でメインメニューを開く。メニュー中のキャンセルで同じ位置の
  ワールドマップへ戻る。
- ワールドマップとメニューの往復や各メニュー画面の切り替えは、従来どおり各6フレームの
  標準フェードを使い、メニューのWindowとカーソル位置を破棄しない。
- ワールドマップ上の決定とキャンセルには、現時点では操作を割り当てない。従来の決定による
  ショップ選択と、キャンセルによるゲーム終了はモック確認用の暫定動線として撤廃する。
- ショップの現在の確認動線は、設定画面のデバッグメニューから提供する。詳細は
  [`shop.md`](./shop.md) を参照する。
- メニュー、ショップ、アイテム、装備は同じ `SaveData` と `InventorySystem` を共有する。

## メインメニュー

- 左側へ現在のパーティの名前、HP、MP、顔を表示し、右側へコマンド、ゲーム情報、
  閉じる操作案内を表示する。
- 初期パーティはフィオラ、セリオンの2人とし、2人とも前列にする。
- 5人以下では顔の間を12px空け、6人目の控えがいる場合は行間を詰める。
  前列の顔はx=20px、後列はx=32pxへ配置する。
- 6人目は常に控えとし、顔とテキストをほかのメンバーより8px下へ置く。
  控えの通常テキストはパレット4番で表示し、名前の横へ `term.formation.reserve` を表示する。
- アイテム、呪文、装備、ステータス、ならびかえ、ゲーム情報、設定、セーブの順に
  コマンドを表示する。各子画面のキャンセルではメインメニューへ戻る。
- メインメニューのコマンド選択中に左入力すると、現在のコマンド位置にかかわらず
  「ならびかえ」へカーソルを移し、そのままメンバー選択を開始する。
- ゲーム情報から開く情報サブメニューとモンスター図鑑の詳細は
  [`information-menu.md`](./information-menu.md) を正本とする。
- フィールドからメニューへ入るたびにMemberの現在HP・MPを表示へ反映し、戦闘やイベントで
  変化した直後も変更前の値を残さない。
- 右側のゲーム情報もフィールドからメニューへ入るたびに現在の `SaveData` から再構築し、
  戦闘報酬で増えた共有経験値やGold、経過したプレイ時間を即時反映する。
- 呪文画面では術者、呪文、対象の順に選ぶ。キャンプ使用可能なHP回復呪文は、生存中かつ
  HPが減っている戦闘参加メンバーへ使用でき、成功時に戦闘と同じ計算で回復してMPを消費する。
  対象選択へ入ると、呪文一覧Windowの右下へグリッド座標`(50, 38, 14, 7)`の最小Windowを
  重ね、選択した呪文種別のアイコンと現在のレベル・熟練度を`アイコン＋L－PP`形式で表示する。
  発動時は [`../program-architecture.md`](../program-architecture.md) のメニュー呪文成長規則で
  熟練度を確定し、発動前から発動後の値へ15フレームで補間する。補間中は入力を受け付けない。
  呪文自体のSEとの競合を避けるため、この補間では数字変化SEを鳴らさない。
  使用後は同じ呪文を選択したまま対象選択へ留まり、有効な対象が残る場合は次の対象へカーソルを
  移す。有効な対象またはMPが残っていない場合も自動では呪文選択へ戻らず、直前の対象位置と
  上昇後の熟練度表示を維持する。呪文選択へ戻る操作はキャンセル入力だけとする。
  対象不在、MP不足、対象外への決定では状態を変更せず共通のエラー通知を行う。
- アイテム画面の「つかう」では、現時点で「きずぐすり」を選ぶと、下部の戦闘参加メンバーから
  対象を選べる。参照先の `POTION` 効果（`on_camp=1` の味方用HP回復）と
  アイテム用の術者能力値20を使って戦闘時と同じ回復量を求め、成功時に所持数を1減らす。
  HPが減っている生存者がいない場合、対象外への決定、フィールドで未対応の効果では状態を
  変更せず共通のエラー通知を行う。使用後も同じアイテムと有効な対象が残る間は対象選択を続ける。
- ならびかえでは異なる2人を選ぶと表示順を交換し、同じ1人を続けて選ぶと前列・後列を
  切り替える。戦闘参加中の生存かつ麻痺していないメンバーを最低1人は前列に残す必要があり、
  死亡・麻痺中のメンバーだけが前列になる変更は受け付けない。控えは常に前列とする。

ステータス、呪文、装備、アイテム、ショップの確定済みレイアウトと操作は、それぞれの
`app/ui/*_menu.py` または [`shop.md`](./shop.md) の実装・仕様を使用する。

## 設定とデバッグ

- 言語、BGM音量、SE音量、画面倍率、ピクセル／なめらか表示、画面フラッシュを変更できる。
  変更はゲーム進行とは別の端末設定へ即時保存し、次回起動時にも維持する。
  言語とBGM音量は即時反映し、SE音量変更時は確認音を鳴らす。
- 画面フラッシュはDA2と同じく初期値を「つうじょう」とする。「おさえる」では会心時の
  全面フラッシュを表示せず、代わりに対象へ`SMASH`を表示する。
- 設定Windowは`(4, 12, 56, 39)`とし、「ゲームを しゅうりょうする」の下へ1行ぶんの
  余白を置いてから、Y座標32以降へ選択項目のガイドを表示する。日本語設定時に言語ガイドの
  2行目へ併記する`Language switching (JP / EN / CN)`だけはDA2準拠の例外として、
  全角化した文字列を英語用6×8フォント`k6x8_gothic.bdf`で表示する。
- 画面倍率は次に「タイトルがめんへ もどる」を実行した時点で反映する。倍率5は
  フルスクリーンとする。
- 「タイトルがめんへ もどる」は、タイトルSceneが未実装の現在は端末設定を維持して
  スタート・ロード画面へ戻る。「はい」の決定後は、メイン、設定、確認の各Windowを標準の
  8フレームで中央へ閉じ、その間は入力を受け付けない。閉じた後も決定、キャンセル、メニュー、
  前後ページの各入力が離されるまで復帰処理を待ち、押しっぱなしの入力をロード画面へ渡さない。
  適用済みの画面倍率から変更がなければPyxelウィンドウを維持してゲーム状態だけを作り直し、
  倍率が変わった場合だけ `pyxel.reset()` 後の `pyxel.init()` でウィンドウを作り直す。
  「ゲームを しゅうりょうする」は確認後に終了する。
- 現在は従来のフィールドモックと同じ確認環境を維持するため、設定画面へ常に
  「デバッグメニュー」を表示する。タイトルSceneと起動オプションを実装した時点で、
  通常起動とデバッグ起動を分離する。
- デバッグメニューのメイン項目は12pxの行送りで表示する。今後項目が増える場合も、
  一覧の標準行送りには同じ値を使う。
- デバッグメニューではパーティLV、Gold、メンバー構成、メンバー状態、テレポートを操作できる。
- 「メンバー状態」では現在のパーティから対象を選び、現在HPを0〜最大HP、現在MPを0〜最大MPの
  範囲で数値入力できる。毒・麻痺はそれぞれ「あり／なし」を決定入力で自由に切り替えられる。
  HPを0にした場合も、デバッグ編集上は毒・麻痺を自動解除しない。
- デバッグメニューから全ショップを選択し、本番のショップ画面を確認できる。
  デバッグ専用文言は `app/ui/debug_text.py` に置き、翻訳データへ含めない。

## セーブ画面

- メインメニューの「セーブ」を決定すると、通常のメニュー内画面と同じ6フレームずつの
  フェードを経てセーブ画面を開く。最上部のメッセージWindowは画面の横幅いっぱいに表示する。
- DA2の手動セーブ枠を基準としてスロット1〜8を用意し、1画面には連続する3スロットを表示する。
  表示中の3スロットはDA2と同様にそれぞれ独立したWindowで囲む。上下入力でスクロールし、
  スロット1と8の間は循環する。
- 各スロットに表示する保存内容は、スロット番号、`saved_at` を
  `YYYY/MM/DD HH:MM` に整形した保存日時、保存時の
  `party.active_character_keys` のうち先頭5人の顔グラフィックだけとする。6人目の控えは表示しない。
  顔はパーティ順に、ショップ画面下部のパーティ表示と同じ32×32pxの寸法・間隔で左から
  横一列に並べ、5人分の列全体が画面の左右中央に来るよう配置する。保存日時はDA2と同じ
  `k8x12S.bdf` で、数字、区切り記号、空白をすべて全角にしてWindow内の右端へ揃える。
  `save.slot` の英語表示は、全角化後も標準英語フォント `k6x8_gothic.bdf` を使用する。
  全8スロットのうち最新の保存日時だけを `POSITIVE_COLOR` で表示する。空きスロットは
  スロット番号だけを表示する。LV、現在地、プレイ時間は表示しない。
- 空きスロットまたは直前に保存したスロットは決定すると直ちに保存する。それ以外の使用済み
  スロットは上書き確認を表示し、「はい」で保存、「いいえ」またはキャンセルで一覧へ戻る。
- 保存成功後は保存日時と顔を更新して「セーブしました」と表示する。失敗時は
  「セーブに しっぱいしました」とエラー通知を行い、一覧に留まる。
- ローカル版の保存先はDA2と同じ規則による
  `~/.config/.pyxel/dungeon-antiqua-zero/save{slot}.json` とし、UTF-8の
  [セーブデータ形式v1](./save-data.md)を一時ファイル経由で置き換える。
- スロット一覧のために `format_version`、`saved_at`、現在パーティのキャラクターキー配列だけを
  読み取る。
- この手動セーブOverlay自体からロードは行わない。起動直後のロードと削除は
  [`start-load.md`](./start-load.md) が扱う。

## 起動

```sh
npm run maps:build
npm start
```

`app/maps` は生成物であるため直接編集しない。制作用マップを変更した場合は、マップエディタの
保存または `npm run maps:build` で再生成する。

## 受け入れ条件

- 現在の `worldmap` 生成物を読み込み、地面、オブジェクト、アニメーションを表示できる。
- 上下左右へ滑らかに移動し、ワールドマップでは方向に対応した従来の2コマ、町・ダンジョンでは
  最初の生存かつ麻痺していないキャラクターの `battle_sprite` に対応する立ち・左右の足運びを
  表示できる。
- 通行不可セルとマップ外へ入らない。
- Gold／アイテムの宝箱を決定または接触で開き、開封中は通常のフィールド入力を抑止できる。
- 開封済み宝箱を開いた画像で復元し、再操作ではメッセージや演出を発生させない。
- カメラが移動へ追従し、端ではマップ範囲内に止まる。
- フィールド位置を維持したまま、メニューとショップを開いて戻れる。
- メインメニューのコマンド選択中に左入力すると、選択位置にかかわらず「ならびかえ」の
  メンバー選択を開始できる。
- ならびかえの前後列切替や控えとの交換では、戦闘参加中の生存かつ麻痺していない前列を
  最低1人残し、死亡・麻痺中のメンバーだけを前列にする操作を拒否できる。
- 戦闘後の毒と麻痺を町・ダンジョンへ持ち越し、ワールドマップへの移動時にだけ解除できる。
- ダンジョンの通常歩行1歩ごとに、毒と装備品の `healing` を合算したHP増減を味方全員へ
  適用できる。
- 歩行時のHP減少で死亡した味方を通知し、生存かつ麻痺していない前列がいなければ、戦闘参加者の
  並び順先頭を前列へ繰り上げて通知できる。
- アイテム画面から「きずぐすり」をHPが減っている生存中の戦闘参加メンバーへ使用し、
  戦闘時と同じ計算でHPを回復して所持数を1減らせる。
- 呪文画面の対象選択中に選択系統のレベル・熟練度を表示し、発動と同時に規定値を加算して
  15フレームで表示値を遷移できる。使用後に有効対象またはMPがなくなっても対象選択と
  上昇後の表示を維持し、キャンセル入力でだけ呪文選択へ戻れる。
- 拠点付近で名称を表示し、有効な入口へ入ると指定マップの到着地点へフェード遷移できる。
- 遷移が成功した拠点だけを訪問済みとして記録できる。
- デバッグメニューから訪問済みのテレポート対象拠点を選び、その到着地点へ移動できる。
- フィールドの決定とキャンセルではショップや終了処理へ遷移せず、フィールド表示を継続できる。
- デバッグメニューから任意のショップを開き、退出後にショップ一覧へ戻れる。
- メニューからセーブ画面を開き、8つの手動スロットへv1形式で保存できる。
- セーブ画面では各スロットを独立したWindowで囲み、スロット番号、保存日時、保存時の
  戦闘参加メンバー5人までの顔を横一列に表示し、最新日時を強調できる。既存スロットは
  確認後に上書きできる。
- 起動直後にDA2準拠のロード画面を表示し、ニューゲーム、保存データのロード、確認後の削除を
  実行できる。「データひきつぎ」は非活性で選択できない。
- 手動セーブOverlayからロードは実行できない。
- `app/main.py` から起動し、ゲーム本体が `tools/` のモック実装へ依存しない。
