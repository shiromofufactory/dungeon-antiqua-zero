# 起動モード仕様

## モードと起動方法

起動時に4種類から1つのモードを選ぶ。オプション省略時は通常モードとする。

| モード | 安定キー | 起動コマンド |
|---|---|---|
| 通常モード | `normal` | `npm start` または `npm run start` |
| 試遊版モード | `exhibition` | `npm run start:exhibition` |
| 体験版モード | `demo` | `npm run start:demo` |
| βテスト版モード | `beta` | `npm run start:beta` |

`npm run` だけを実行すると、起動モード別のコマンドを一覧で確認できる。
各モードのscriptは既存の `start` へオプションを渡すため、起動前の攻撃ポーズ生成も共通で行う。
従来の `npm start -- --mode <安定キー>` も引き続き利用できる。

`python3 -B app/main.py --mode <安定キー>` でも同じモードを指定できる。
`--mode normal` は通常起動と同じ。未対応の値や不正なオプションは、Pyxelの初期化前に
終了コード2で拒否する。`--help` は選べるモードを表示する。

## モードの寿命

- モードは起動中の固定値とし、端末設定やセーブデータへ保存しない。
- タイトル画面への復帰、ニューゲーム、ロードでは現在の起動モードを維持する。
- 別モードで保存したデータをロードしても、モードは起動時の指定に従う。
- 起動時にモードを指定し直すことで、同じイベントを各モードで確認できる。

## タイトルからの開始

- 全モードで [仮タイトル](./start-load.md#仮タイトル) から始める。
- 通常・体験版・βテスト版は、タイトルの決定入力後にスタート・ロード画面へ進む。
- 試遊版は、タイトルの決定入力後にロード画面を経由せずニューゲームを始める。
  既存セーブがあっても、初期パーティと開始イベントから始める。
- タイトル復帰後も、同じモードの開始経路を使う。
- イベントの [ゲームをリセット](./events.md#ゲームをリセット) でも同じモードのタイトルへ戻る。
  試遊版の終了宣言には、終了メッセージの直後にこのコマンドを置く。

## 初期パーティ

- 試遊版のニューゲームでは、パーティLVの基準となるフィオラの内部LVを3とする。
  ほかの初期メンバーと初加入メンバーは、既存の加入規則どおりフィオラの内部LVへ
  `content/data/characters.json` の `lv_diff` を加え、1〜99へ収める。
- 通常・体験版・βテスト版のフィオラは従来どおり内部LV1で開始する。
- HP・MPは開始LVに対応する理論値で全回復状態にする。初期の共有経験値はフィオラの
  開始LVに必要な累計値とし、試遊版は26、ほかのモードは0で開始する。
- キャラ別の経験値補正は、開始LVの累計必要経験値から初期の共有経験値を引いた値とする。
  フィオラの補正は0となり、ほかのメンバーも戦闘後やロード時に開始LVを維持できる。
- フィオラの初期武器・呪文熟練度は従来の加入規則を維持する。使用可能な種別は1-00で始める。
- ロードでは保存されたLV、HP・MP、熟練度、経験値補正を復元し、試遊版の開始LVを再適用しない。

## 成長上限

| モード | 武器・呪文の成長上限 | 共有経験値の上限 |
|---|---|---|
| 通常モード | 適性による上限 | 999,999 |
| 試遊版モード | 2-99 | 500 |
| 体験版モード | 4-99 | 5,000 |
| βテスト版モード | 適性による上限 | 999,999 |

- 武器・呪文の成長上限は、適性による上限と上表の低いほうを使う。使用不可は0-00を維持する。
- 上限LVでも熟練度99までは加算できる。超える分だけを切り捨て、次のLVへ繰り上げない。
- NPC加入時の武器・呪文の値がすでに上限を超えている場合は、その値を維持する。
  以後の熟練度加算は0とし、上限値へ引き下げない。再加入・ロードでも保存済みの値を維持する。
- 武器・呪文の上限は、勝利・逃走・フェードでの戦闘精算、メニューの回復呪文、
  自動回復のすべてへ適用する。実際に増えた熟練度だけを成長表示へ反映する。
- 経験値はパーティ共有の累計値を制限し、キャラ別の経験値補正値には制限をかけない。
  フィオラは試遊版で内部LV10、体験版で内部LV19まで到達できる。
- 戦闘経験値は上限までの残り分だけを加算する。上限到達後は0とし、勝利画面にも実際の
  加算値を表示する。Goldやお宝の獲得は従来どおり行う。
- メインメニューの累計経験値の数値は、現在のモードの上限以上で `POSITIVE_COLOR` にする。
  上限未満は `DEFAULT_TEXT_COLOR` とし、見出しやほかの集計項目の色は従来どおりとする。
- ほかのモードで作ったセーブをロードし、経験値がすでに上限を超えている場合は保存値を
  維持し、新しい経験値は加算しない。
- 上限は現在の起動モードから適用する実行時の制約とし、セーブ形式へ追加しない。
  通常・βテスト版では武器・呪文は適性の範囲で、共有経験値は999,999まで再び成長できる。

## 手動セーブ

- 試遊版ではメインメニューのセーブを無効にする。項目は非活性表示のままカーソル対象へ
  残し、決定すると既存のエラー音と横揺れのアラートを出してメニューに留まる。
- セーブ画面へのフェード、スロット一覧の読込、手動スロットへの書込は開始しない。
- 通常・体験版・βテスト版では手動セーブを利用できる。
- マップ移動時のオートセーブは [セーブデータ仕様](./save-data.md) の規則を使う。
  メニュー項目の色と操作は [フィールド仕様](./field.md#メインメニュー) を参照する。

## デバッグメニュー

- 現在は通常モードだけ設定画面にデバッグメニューを表示する。
- 試遊版・体験版・βテスト版では、デバッグ項目の文言とカーソル候補を除く。
  ゲーム側のデバッグ画面開始処理も起動モードを確認する。
- 設定Windowの寸法と残りの項目の座標は [フィールド仕様](./field.md#設定とデバッグ) に従う。
- 通常モードのデバッグ表示も、最終的には非表示にする。現段階では維持する。

## イベント条件

[イベント仕様](./events.md#条件) の `launch_mode` 条件で現在の起動モードを比較する。
フィールド・戦闘イベントの両方で利用でき、`all`・`any`・`not` と組み合わせられる。
同じ条件を使うミッションの表示条件でも現在の起動モードを評価する。

イベントエディタで条件「起動モード」を選び、4モードから対象を選択する。
例えば試遊版でだけメッセージを表示する分岐は次の形式とする。

```json
{
  "command": "branch",
  "condition": {"type": "launch_mode", "mode": "exhibition"},
  "then": [{"command": "message", "message_id": "sample.exhibition"}],
  "else": []
}
```

`message_id` は既存のメッセージ正本へ登録されたIDを使う。モードは上表の安定キーのみを
受け付け、省略、未知の値、数値、余分な属性は制作用検証と実行時loaderの両方で拒否する。

## 受け入れ条件

- `npm run` の一覧にモード別の起動scriptが表示され、各コマンドから対応するモードで起動できる。
- オプション省略と各モード指定で、対応する起動モードをGameへ渡せる。
- 全モードでタイトルから始まり、試遊版だけ決定入力からニューゲームへ直接進める。
- 試遊版でだけニューゲームのパーティLVを3から開始し、成長・保存・ロードでも維持できる。
- 試遊版の初期共有経験値は26で、フィオラの内部LVと経験値表示が一致する。
  戦闘経験値は26に加算し、通常のLV4必要累計値でレベルアップする。
- ロード時は保存されたLVを尊重し、起動モードの初期値で上書きしない。
- 試遊版は2-98へ熟練度2以上を加えても2-99、体験版は4-98へ同様に加えても4-99で止まる。
  戦闘精算、逃走、メニュー呪文、自動回復で同じ上限になり、上限を超えて加入したNPCは成長しない。
- 試遊版の共有経験値495に戦闘経験値15を加えた場合は500となり、獲得表示は5となる。
  体験版は4,995に同様に加えた場合5,000で止まり、上限到達後の獲得表示は0となる。
- 成長上限で保存・復元しても値を保持し、通常・βテスト版ではそれ以上に成長できる。
- 累計経験値が試遊版500、体験版5,000、通常・βテスト版999,999に達すると、メインメニューの
  経験値の数値だけが `POSITIVE_COLOR` になる。ロードなどで下回った場合は通常色へ戻る。
- 通常モード以外ではデバッグ文言・カーソル候補・画面開始を無効にできる。
- 試遊版のセーブ項目を非活性表示にし、決定してもアラートだけでセーブ画面を開かない。
  ほかの3モードでは従来どおり手動セーブ画面へ進める。
- タイトル復帰後も起動モードを維持し、次のニューゲームに同じ初期パーティ規則を適用できる。
- フィールド・戦闘イベントで4モードを分岐判定でき、入れ子の条件でも同じ結果になる。
- エディタでモード条件を追加・変更でき、Undo・Redoと保存用JSONへ反映できる。
