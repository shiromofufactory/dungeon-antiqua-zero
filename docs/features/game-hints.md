# ゲーム内ヒント

## 設定と表示条件

- 設定の `settings.in_game_hints.label` は `settings.on` / `settings.off` の2択とし、
  左右入力で切り替える。初期値は有効。
- `Settings.in_game_hints_enabled` として端末設定へ即時保存する。古い設定にこの項目が
  ない場合も有効とする。ゲーム進行のセーブデータには含めない。
- 最初のヒントは `hint.load.mission`。セーブデータのロードが成功したとき、毎回表示する。
  ロード後のフィールドへのフェードイン完了を待って開閉アニメーションを更新する。
- ニューゲーム、ロード失敗、設定が無効の場合は表示しない。

## Windowと操作

座標・寸法は4×4pxグリッド。

- 共通Window `(0, 20, 64, 20)` を使い、標準Windowの8フレームの開閉アニメーションを付ける。
- 見出しは必ず `hint.heading` をX=4、Y=2に置く。
- 本文はX=4に置き、見出しの次の行からメッセージ欄・会話ログと同じ行間で表示する。
  日本語・簡体字中国語はY=6から4グリッド（16px）間隔、英語はY=5から3グリッド（12px）間隔。
  ロード後のヒント本文の各行の間に空行を挿入しない。
- 日本語はメッセージ欄と同じ `FontRole.LARGE`（`umplus_j12r.bdf`、12pxフォント）を
  見出しと本文に使用する。他言語もメッセージ欄と同じ言語別のLARGEフォントを使う。
- 開く操作から押し続けた決定・キャンセルは、入力が離されるまで閉じる操作に使わない。
  開ききった次のフレーム以降、決定またはキャンセルで閉じ始める。
- 表示中・開閉中はフィールド更新と操作を停止し、閉じきったフレームの入力も消費する。
  BGMは続ける。フィールド待機時の操作ナビは表示しない。
- Esc／Startの強制割り込みゲームメニューはヒントの上で開き、再開時は同じヒントの状態へ戻る。

## 受け入れ条件

- 設定を無効にして再起動しても無効を保持し、ロード後のヒントは表示されない。
- 有効なロード直後には見出しと本文がWindow内に収まり、日本語の漢字もメッセージ欄と
  同じフォントで表示される。
- 決定・キャンセルのどちらでも閉じられ、開く操作の押しっぱなしでは閉じない。
- 開閉中に移動・メニュー操作がフィールドへ伝わらない。
- 情報メニューの先頭には `information.mission` があり、現在の本文は空欄。

回帰検証は `python3 -B -m unittest tests.test_hint tests.test_settings_system tests.test_state tests.test_game`
で実行する。
