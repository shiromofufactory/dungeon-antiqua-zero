# タイトル・スタート・ロード画面仕様

## 位置付け

本書は、起動直後の仮タイトル、DA2準拠の操作説明と
スタート・ロード画面を定める。セーブJSONの形式と復元時の検証は
[`save-data.md`](./save-data.md)、ロード後のフィールドは [`field.md`](./field.md) を参照する。
起動オプション、モードの保持、試遊版の初期パーティLVは
[`launch-modes.md`](./launch-modes.md) を参照する。

## 仮タイトル

- 全モードで起動直後に仮タイトルを表示する。黒背景に `title.press_start` の英文だけを
  表示し、ロゴ、Window、カーソルは置かない。文言の正本は `content/data/texts.json` とする。
- 文言内のAとZは、既存の `%GAMEPAD_A%` と `%KEY_Z%` の8×8pxアイコンで表示する。
  入力種別によらず両方を表示し、共通のタグ描画で文字と同じ高さへそろえる。
- 設定言語によらず英語用フォント `k6x8_gothic.bdf` を使用する。画面は256×240pxとし、
  文字とアイコンを含む描画幅と高さを使って縦横中央へ配置する。
- 決定入力（Z／Return／ゲームパッドA）を1回受け付け、標準フェードで次の画面へ進む。
  方向入力や通常キャンセルでは画面を切り替えない。押しっぱなしの決定入力を次画面の
  新しい決定として扱わない。
- 初回プレイ時と、タイトルを決定した入力種別が前回説明を確認した入力種別と異なる場合は、
  完全暗転時に後述の操作説明Windowを生成する。試遊版では毎回表示する。
- 操作説明が不要な通常・体験版・βテスト版では、完全暗転時にスタート・ロード画面を生成する。
  セーブ一覧を読むのはこの時点とし、タイトル表示中には読まない。
- 試遊版では操作説明の確認後、ロード画面を生成せず後述のニューゲーム開始処理へ直接進む。
  セーブの有無によらず、内部LV3の初期パーティとニューゲーム専用イベントから始める。
- タイトル表示中も `da3-welcome` をループ再生する。プレイ時間は計上しない。
- 設定画面や強制割り込みゲームメニューからのタイトル復帰でも、この画面へ戻る。

## 開始時の操作説明

- DA2と同様、タイトルで使用したキーボード／ゲームパッドに対応する説明を表示する。
  端末設定 `control_guide_device` が未保存（旧設定を含む）の場合を初回とし、
  保存済みの値が現在の入力種別と異なる場合も再表示する。
  試遊版は保存済みの入力種別にかかわらず、タイトルから進むたびに表示する。
- Windowは `(4, 16, 56, 28)`、文字のX座標は4グリッド、見出しと4操作のY座標は
  `2, 8, 11, 14, 17`、確認・戻る案内は23グリッドとする。
  操作の4行は12px間隔、見出しと移動、メニューと確認案内の間はそれぞれ空行1行分とする。
  文言は `start.controls.keyboard`、`start.controls.gamepad`、`start.controls.prompt` を参照する。
- 移動（矢印キー／十字キー）、決定（Z・Enter／A）、キャンセル（X・Backspace／B）、
  メニュー（S・Tab／X・Y）の4操作を説明する。既存のキー・ボタンアイコンを使用し、
  Tabはアイコンではなく文字で表示する。
- タイトルの決定入力が離されるまで確認を受け付けない。Windowが開き終わった後の
  新しい決定入力で説明した入力種別を端末設定へ保存し、標準フェードで次へ進む。
  保存に失敗した場合は既存のエラー通知を行い、説明に留まる。
- 通常・体験版・βテスト版はスタート・ロード画面、試遊版はニューゲーム開始処理へ進む。
  確認の押しっぱなしで、次画面の項目や開始イベントのメッセージを決定しない。
- キャンセルでは閉じるアニメーション後に仮タイトルへ戻り、説明済み設定は更新しない。
  方向入力やメニュー入力では説明を閉じない。
- 説明中に入力種別が変わった場合は内容を更新して開き直し、決定・キャンセルの
  リリース後に新しい入力を受け付ける。確認した時点で説明した入力種別を保存する。
- 前回の入力種別はセーブスロットへ保存せず、タイトル復帰・ゲームリセット・アプリ再起動でも
  端末設定から保持する。プレイ中の入力種別変更ではこのWindowを割り込ませず、次のタイトルで判定する。
- 説明中は `da3-welcome` を継続し、セーブ一覧を読まず、プレイ時間も計上しない。
  ゲーム内ヒントのON/OFFには依存しない。強制割り込みゲームメニューからの復帰は説明を継続する。

## 画面構成

- 画面は256×240pxとし、上段に `(0, 0, 64, 6)` のコマンドWindow、下段に
  `(0, 6, 64, 18)` を先頭として高さ18グリッド単位のスロットWindowを3個表示する。
- 上段は左から `start.new_game`、`start.delete_data`、`start.inherit_data` を表示する。
- 「データひきつぎ」は現在未実装のため `DISABLED_COLOR` で表示し、カーソル対象にしない。
- DA2と同様にロード専用のオートセーブ枠（スロット0）と、手動セーブと共通の
  スロット1〜8を扱い、1画面には連続する3枠を表示する。スロット0の表示文言は
  `save.auto_slot` を使う。
  各スロットは独立したWindowで囲み、上下移動に合わせて一覧をスクロールする。
- 使用済みスロットはスロット番号、その下に `YYYY/MM/DD HH:MM` 形式の保存日時、上段右側に保存地点名、保存時の
  戦闘参加メンバー先頭5人の顔を表示する。最新日時だけを `POSITIVE_COLOR` にする。
  保存時にHPが0だったメンバーの顔はグレースケール用パレットで表示する。
  空きスロットはスロット番号だけを表示する。
  保存地点名の解決・フォント・右寄せ、日時の配置、顔の上端（Window上端から32px）は
  [セーブ画面](./field.md#セーブ画面)と共通とし、オートセーブ枠にも適用する。
- 文言の正本は `content/data/texts.json` の `start.*`、`save.slot`、
  `settings.yes`、`settings.no` とする。
- `save.slot` の英語表示は、全角化後も標準英語フォント `k6x8_gothic.bdf` を使用する。

## 初期選択

- 有効な使用済み枠が1つ以上あれば、オートセーブも含めて保存日時が最新の枠を選択して
  スロット一覧へフォーカスする。
- 使用済みスロットがなければ「ニューゲーム」を選択して上段へフォーカスする。
- 上段の左右入力は有効な項目間だけを循環し、「データひきつぎ」には停止しない。
- 上段で上下入力するとスロット一覧へ移る。通常ロード選択中にオートセーブ枠から上、
  またはスロット8から下へ入力すると上段へ戻る。

## ニューゲームとロード

- 「ニューゲーム」を決定すると標準フェードを開始し、完全暗転時に初期状態の
  妖精の里へ切り替える。開始位置と向きは [フィールドの初期状態](./field.md#初期状態) に従う。
  フィールド表示前にプログラム側で画面の明るさを即座に0%へ設定する。
  フィールドBGMの開始後、ニューゲーム専用イベント
  `faily_village.prologue` を起動する。画面遷移のフェードイン中・完了後も、開始イベントが
  明るさを変更するまで0%を維持する。
- 使用済みスロットを決定すると、JSON、形式バージョン、全ゲーム状態、マスター参照、
  マップの存在と再開セルの座標範囲をフィールドへ反映する前に検証する。マップ編集によって
  保存セルが通行不能へ変わっていてもロードは拒否せず、そのセルから再開する。
- 検証成功後に標準フェードを開始し、完全暗転時に復元済み状態をまとめて反映して
  保存地点のフィールドから再開する。保存時に開いていたOverlayは復元しない。
- ロード成功時だけ、ゲーム内ヒントが有効ならフェードイン完了後にミッション案内を表示する。
  ニューゲーム・不正データ・空きスロットでは表示しない。詳細は [ゲーム内ヒント](./game-hints.md)。
- 空きスロットまたは不正なデータを決定した場合はエラー通知を行い、画面に留まる。
  不正データの一部をゲーム状態へ反映したり、初期状態で代替したりしない。
- スタート・ロード画面を表示している間は `da3-welcome` をループ再生する。
- ニューゲームまたはロードの切り替え成立時に、BGMを現在マップの `bgm_id` へ切り替える。

## データの削除

- 「データのしょうきょ」を決定すると、使用済みの手動データがある場合だけ削除選択へ移る。
- 削除選択では同じ8スロットを上下に循環できる。キャンセルすると、上段の
  「データのしょうきょ」を選択した状態へ戻る。
- オートセーブ枠は削除選択に表示せず、削除できない。
- 使用済みスロットを決定すると「はい／いいえ」の確認Windowを表示する。
  「はい」でスロットファイルを削除し、一覧を空き状態へ更新する。
  「いいえ」またはキャンセルでは削除しない。
- 空きスロットの決定、またはファイル削除失敗ではエラー通知を行い、削除選択に留まる。

## 受け入れ条件

- 起動直後に設定言語によらずAボタン・Zキーのアイコンを含む指定の英文を画面中央へ表示できる。
- 初回と入力種別変更時に、対応する4操作の説明を表示し、確認した入力種別を次回起動まで保持できる。
  同じ入力種別の次回開始では説明を省略し、試遊版は毎回表示できる。
- 操作説明の確認後（不要ならタイトルの決定後）、通常・体験版・βテスト版は
  上段コマンドと3件のスロットを持つロード画面へ進める。
- 試遊版は毎回の操作説明を確認した後、セーブ一覧を読まず、ロード画面を経由せず
  ニューゲームの開始イベントへ進める。
- 決定入力の押しっぱなしで次画面の項目やメッセージを決定しない。
- 最新の使用済み枠を初期選択し、オートセーブ枠と手動8スロットをスクロールして選択できる。
- 「データひきつぎ」が非活性表示となり、決定もカーソル停止もできない。
- ニューゲームは初期フィールド、ロードは保存地点のフィールドへフェード遷移できる。
- 保存セルが現在のマップで通行不能でもロードでき、保存座標から再開できる。
- コマンド記憶が有効なら保存時の戦闘の選択記憶も復元できる。
  記憶項目がない旧セーブは記憶なしとして読める。形式は [セーブデータ](./save-data.md) を参照する。
- ニューゲームでだけ `faily_village.prologue` が起動し、保存データのロードでは起動しない。
- 壊れたデータを安全に拒否し、ロード前の状態を変更しない。
- 使用済みスロットを確認後に削除でき、空きスロット表示へ更新できる。
