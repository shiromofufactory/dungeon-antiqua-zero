# スタート・ロード画面仕様

## 位置付け

本書は、タイトルSceneが未実装の現段階で起動直後に表示する、DA2準拠の
スタート・ロード画面を定める。セーブJSONの形式と復元時の検証は
[`save-data.md`](./save-data.md)、ロード後のフィールドは [`field.md`](./field.md) を参照する。

## 画面構成

- 画面は256×240pxとし、上段に `(0, 0, 64, 6)` のコマンドWindow、下段に
  `(0, 6, 64, 18)` を先頭として高さ18グリッド単位のスロットWindowを3個表示する。
- 上段は左から `start.new_game`、`start.delete_data`、`start.inherit_data` を表示する。
- 「データひきつぎ」は現在未実装のため `DISABLED_COLOR` で表示し、カーソル対象にしない。
- DA2と同様にロード専用のオートセーブ枠（スロット0）と、手動セーブと共通の
  スロット1〜8を扱い、1画面には連続する3枠を表示する。スロット0の表示文言は
  `save.auto_slot` を使う。
  各スロットは独立したWindowで囲み、上下移動に合わせて一覧をスクロールする。
- 使用済みスロットはスロット番号、`YYYY/MM/DD HH:MM` 形式の保存日時、保存時の
  戦闘参加メンバー先頭5人の顔を表示する。最新日時だけを `POSITIVE_COLOR` にする。
  保存時にHPが0だったメンバーの顔はグレースケール用パレットで表示する。
  空きスロットはスロット番号だけを表示する。
- 文言の正本は `content/data/texts.json` の `start.*`、`save.slot`、
  `settings.yes`、`settings.no` とする。
- `save.slot` の英語表示は、全角化後も標準英語フォント `k6x8_gothic.bdf` を使用する。

## 初期選択

- 有効な使用済み枠が1つ以上あれば、オートセーブも含めて保存日時が最新の枠を選択して
  スロット一覧へフォーカスする。
- 使用済みスロットがなければ「ニューゲーム」を選択して上段へフォーカスする。
- 上段の左右入力は有効な項目間だけを循環し、「データひきつぎ」には停止しない。
- 上段で上下入力するとスロット一覧へ移る。通常ロード選択中にオートセーブ枠から上、
  またはスロット8から下へ入力すると上段へ戻る。

## ニューゲームとロード

- 「ニューゲーム」を決定すると標準フェードを開始し、完全暗転時に初期状態の
  ワールドマップへ切り替える。フィールドBGMの開始後、ニューゲーム専用イベント
  `worldmap.prologue` を起動し、イベントを表示した状態でフェードインする。
- 使用済みスロットを決定すると、JSON、形式バージョン、全ゲーム状態、マスター参照、
  マップの存在と再開セルの座標範囲をフィールドへ反映する前に検証する。マップ編集によって
  保存セルが通行不能へ変わっていてもロードは拒否せず、そのセルから再開する。
- 検証成功後に標準フェードを開始し、完全暗転時に復元済み状態をまとめて反映して
  保存地点のフィールドから再開する。保存時に開いていたOverlayは復元しない。
- ロード成功時だけ、ゲーム内ヒントが有効ならフェードイン完了後にミッション案内を表示する。
  ニューゲーム・不正データ・空きスロットでは表示しない。詳細は [ゲーム内ヒント](./game-hints.md)。
- 空きスロットまたは不正なデータを決定した場合はエラー通知を行い、画面に留まる。
  不正データの一部をゲーム状態へ反映したり、初期状態で代替したりしない。
- スタート・ロード画面を表示している間は `da3-welcome` をループ再生する。
- ニューゲームまたはロードの切り替え成立時に、BGMを `da3-field` へ切り替える。

## データの削除

- 「データのしょうきょ」を決定すると、使用済みの手動データがある場合だけ削除選択へ移る。
- 削除選択では同じ8スロットを上下に循環できる。キャンセルすると、上段の
  「データのしょうきょ」を選択した状態へ戻る。
- オートセーブ枠は削除選択に表示せず、削除できない。
- 使用済みスロットを決定すると「はい／いいえ」の確認Windowを表示する。
  「はい」でスロットファイルを削除し、一覧を空き状態へ更新する。
  「いいえ」またはキャンセルでは削除しない。
- 空きスロットの決定、またはファイル削除失敗ではエラー通知を行い、削除選択に留まる。

## 受け入れ条件

- 起動直後に上段コマンドと3件のスロットを持つロード画面を表示できる。
- 最新の使用済み枠を初期選択し、オートセーブ枠と手動8スロットをスクロールして選択できる。
- 「データひきつぎ」が非活性表示となり、決定もカーソル停止もできない。
- ニューゲームは初期フィールド、ロードは保存地点のフィールドへフェード遷移できる。
- 保存セルが現在のマップで通行不能でもロードでき、保存座標から再開できる。
- コマンド記憶が有効なら保存時の戦闘の選択記憶も復元できる。
  記憶項目がない旧セーブは記憶なしとして読める。形式は [セーブデータ](./save-data.md) を参照する。
- ニューゲームでだけ `worldmap.prologue` が起動し、保存データのロードでは起動しない。
- 壊れたデータを安全に拒否し、ロード前の状態を変更しない。
- 使用済みスロットを確認後に削除でき、空きスロット表示へ更新できる。
