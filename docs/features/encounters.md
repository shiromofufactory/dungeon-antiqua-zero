# エンカウントと戦闘復帰仕様

## 位置付け

本書はダンジョン歩行から戦闘Sceneを開始し、戦闘結果をフィールドへ戻すまでの条件と演出を
定める。戦闘中の操作と表示は [`battle.md`](./battle.md)、フィールド移動は
[`field.md`](./field.md)、保存形式は [`save-data.md`](./save-data.md)を参照する。

## ランダムエンカウント

- `SaveData.encounter_count` をエンカウント変数とする。ニューゲームでは0から開始し、セーブ対象とする。
- dungeon profileで通常の1歩を完了するたび、DA1と同じく1〜4の整数をランダムに加算する。
- 難易度にかかわらず160以上で戦闘を開始し、変数を0へ戻す。DA1の階層別補正と
  ハードモード補正は適用しない。
- world／town profileでは加算しない。ドア、宝箱、通常イベント、マップ移動が成立した歩行では
  即時エンカウントを発生させない。
- dungeonマップは `random_encounter.monster_level` に1〜9または `dynamic`、
  `random_encounter.danger` に `low` または `high` を持つ。`dynamic` はゲーム進行度から
  モンスターレベルを決める指定であり、`low` は同じレベルの `high` より同時出現数を少なく扱う。
- `random_encounter.polarity` は `yang`、`neutral`、`yin` のいずれかとする。さらに
  `allow_demons`、`allow_humans`、`allow_giants`、`allow_large_animals` で候補の出現可否を持つ。
  悪魔はmonsterの `tribe == "DEMON"`、人間は `tribe` が `HUMAN` または `MAGE`、巨人は
  `tribe == "GIANT"`、大型動物は `large_animal == 1` を対象とする。
- モンスターレベルが `dynamic` の場合、現時点では常にレベル1として扱う。ゲーム進行度に
  応じた判定規則は別途仕様化した時点で差し替える。
- 解決済みのマップモンスターレベルを `L` とする。編成の最大出現数 `M` は危険度が
  `high` なら5、`low` なら4とする。候補母集団は `lv == L` とし、危険度が `high` の場合だけ
  `lv == L + 1` かつ `early_appear == 1` も加える。同じモンスターキーは母集団へ重複追加しない。
- `allow_demons == false` では `DEMON`、`allow_humans == false` では `HUMAN` と `MAGE`、
  `allow_giants == false` では `GIANT` を候補から外す。`allow_large_animals == false` では
  `large_animal == 1` を候補から外し、`true` では通常候補と同じ条件で含める。
- 傾向が `yang` なら `weakness` に `炎` を含む候補、`yin` なら `冷` を含む候補を外す。
  `neutral` では両者を候補に残すが、炎または冷弱点を持つ各候補の抽選重みを通常候補の
  1/2とする。両方の弱点を持つ候補も重みは1/2とする。
- 母集団から1種類を重み付き抽選し、1〜`max_occ` 体を編成へ加える。危険度が `low` の場合、
  `max_occ` は1/2の小数切り上げとする。追加後の総数が `M` を超える場合はそのグループを
  加えず編成を終了する。
- グループ追加後、`M - 現在の総出現数` が1〜`M`の乱数より小さければ編成を終了する。
  継続する場合は1/2の確率で `L` を1下げ（最低1）、新しい `L` で母集団の作成から繰り返す。
  1グループ目は後衛、2グループ目以降は前衛として扱う。編成完了時に前衛が1体もいない場合は、
  戦闘開始時に生存中のモンスター全員を前衛へ昇格させる。
- 初回の母集団が空になる設定は編成データ不正として扱う。2グループ目以降で母集団が空に
  なった場合は、そこまでの編成で終了する。
- DA1にあるドアを開けた際の個別抽選は実装しない。
- この経路から生成する戦闘だけ不意打ち抽選を有効にする。抽選式、スキル「けいかい」、
  成立後の隊列と手番処理は [`battle.md`](./battle.md) の「不意打ち」に従う。

## 戦闘開始演出

- エンカウント成立時にフィールド移動を停止し、BGM ID `da3-encount` をループなしで再生する。
- 成立時点のフィールド画面全体を1回だけ画像へ保存する。拡大開始と同時にPCを非表示とし、
  保存対象にはPCを除いたマップ、actor、宝箱、前景を含む。
- 非表示前のPCスプライト中心を拡大中心とし、保存画面を最初の32フレームで1倍から4倍へ
  加速的に拡大する。残りの8フレームは4倍を維持する。
- 開始直後から時計回りに回転し、最初はゆっくり、後のフレームほど回転速度を上げながら
  最終的に2回転する。同時に32フレームかけてゆっくりホワイトアウトし、最後の8フレームで
  白から黒へフェードアウトする。
  40フレームは現在の `da3-encount` の長さに合わせる。
- 完全暗転時に本編の `BattleScene` を生成する。戦闘Scene自身の開始フェードインへ連続させ、
  フィールド画像を再描画しない。

## 戦闘終了とフィールド復帰

- 最後の敵の死亡演出が完了したら勝利メッセージと成長リザルトを順に表示し、2画面目を決定入力で閉じた時点で `BattleResult.VICTORY` を確定する。
- 初回の戦闘突入、成長リザルト表示、全滅復帰では、設定が有効な場合に対応するゲーム内ヒントを
  1回だけ表示する。表示タイミングと保存フラグは [`game-hints.md`](./game-hints.md) を正本とする。
- 勝利時は完了済み戦闘回数を1増やす。逃走と全滅では増やさない。
- 勝利は戦闘画面を標準6フレームでフェードアウトし、完全暗転時にフィールドへ
  切り替えて6フレームでフェードインする。全滅は完全暗転後、黒背景上に顔画像
  `(0, 224)` と `defeat.return.message` を標準メッセージOverlayで表示する。最終ページの
  確認後、フィールドへ切り替えるのと同時にテレポート音（SE 8）を再生する。完全暗転を
  維持したままSEの終了を待ち、その後6フレームでフェードインする。
- 逃走はBattleScene内で暗転済みのため、完全暗転した状態でフィールドへ切り替え、
  標準6フレームのフェードインだけを行う。
- フィールドへの切り替え時に現在マップのBGMを先頭からループ再生する。
- ダンジョン歩行による全滅では、復帰確定時に継続中のフィールドBGMを停止する。テレポート音
  （SE 8）の終了後、フェードイン開始と同時に現在マップのBGMを先頭からループ再生する。
- 睡眠、混乱、スタン、防御・素早さ補正は戦闘限定状態としてフィールドへの切り替え時に解除する。
  勝利と逃走では毒と麻痺を解除せず、元のフィールドへ持ち越す。
- 勝利と逃走ではエンカウントしたセルと向きを維持する。
- 全滅では、現在位置から最も近い `sites` のうち、別マップを移動先とするものを
  ダンジョン出口として選ぶ。その出口セルを直接踏まない隣接通行可能セルへ移動し、出口を向く。
  複数候補の距離が同じ場合は安定IDと座標で決定し、再現可能にする。
- 全滅では暗転後のメッセージを確認して入口へ戻す際に、現在パーティ全員のHP・MPを最大値へ
  戻し、すべての状態異常と戦闘中補正を解除する。使用可能な出口がない不正なマップでも
  全回復は行い、現在位置だけを維持する。

## セーブ互換

書き出すv1セーブの `progress.encounter_count` は必須とする。この項目を追加する前に作られた
既存のv1セーブだけは0として復元し、次回保存時に項目を追加する。戦闘開始演出、戦闘中、
戦闘終了フェード中は従来どおり保存できない。

## 受け入れ条件

- dungeon profileの完了歩行だけがエンカウント変数を1〜4増やし、160以上でマップ設定に
  応じて生成した1〜5体の編成との戦闘を開始する。
- 通常ランダムエンカウントから開始した戦闘だけが不意打ちを抽選する。
- エンカウント変数を保存・復元でき、旧v1セーブは0として復元できる。
- PCを中心にフィールド全体を加速的に拡大・2回転させながらホワイトアウトし、最後に暗転して
  戦闘を表示する。回転は開始直後から徐々に加速する。
- 最後の敵を倒す、逃走する、全滅する各結果からフェードを介してフィールドへ復帰する。
- 勝利と逃走では毒と麻痺を元のフィールドへ持ち越し、全滅ではHP・MPとともに全回復する。
- 全滅時は完全暗転後に指定の顔画像と4行の復帰メッセージを2ページで表示し、確認後に
  最寄りのダンジョン出口直前へ移動して出口を向く。
