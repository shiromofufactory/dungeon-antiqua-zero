# エンカウントと戦闘復帰仕様

## 位置付け

本書はダンジョン歩行から戦闘Sceneを開始し、戦闘結果をフィールドへ戻すまでの条件と演出を
定める。戦闘中の操作と表示は [`battle.md`](./battle.md)、フィールド移動は
[`field.md`](./field.md)、保存形式は [`save-data.md`](./save-data.md)を参照する。

## ランダムエンカウント

- `SaveData.encounter_count` をエンカウント変数とする。ニューゲームでは0から開始し、セーブ対象とする。
- dungeon profileで通常の1歩を完了するたび、DA1と同じく1〜4の整数をランダムに加算する。
- 難易度にかかわらず120以上で戦闘を開始し、変数を0へ戻す。DA1の階層別補正と
  ハードモード補正は適用しない。
- 同じdungeonマップにいる間にフィールドでFADEを発動した場合は、現在のエンカウント変数を
  変更せず、発生ボーダーだけを2倍の240へ変更する。戦闘から同じマップへ戻った場合は維持し、
  別マップへ移動した時点で解除する。FADEの有効状態はセーブ対象にしない。
- world／town profileでは加算しない。ドア、宝箱、待機する効果がある通常イベント、
  マップ移動が成立した歩行では即時エンカウントを発生させない。即時完了するイベントのセルは
  通常の歩行と同じく扱う。
- dungeonの各フロアは `random_encounter.enabled` のbooleanでランダムエンカウントの有無を
  指定する。`false`（エンカウントなし）のフロアでは変数を加算・リセットせず、閾値以上でも
  ランダム戦闘を開始しない。エンカウントありのフロアへ移動した後は保持した変数から再開する。
  省略時は `true` として既存データの動作を維持する。イベント戦闘とデバッグ戦闘は引き続き開始できる。
- dungeonマップは `random_encounter.monster_level` に1〜9または `dynamic`、
  `random_encounter.danger` に `low` または `high` を持つ。`dynamic` はゲーム進行度から
  モンスターレベルを決める指定であり、`low` は同じレベルの `high` より同時出現数を少なく扱う。
- `random_encounter.polarity` は `yang`、`neutral`、`yin` のいずれかとする。さらに
  `allow_demons`、`allow_humans`、`allow_giants`、`allow_large_animals` で候補の出現可否を持つ。
  悪魔はmonsterの `tribe == "DEMON"`、人間は `tribe` が `HUMAN` または `MAGE`、巨人は
  `tribe == "GIANT"`、大型動物は `large_animal == 1` を対象とする。
- モンスターレベルが `dynamic` の場合、現時点では常にレベル1として扱う。ゲーム進行度に
  応じた判定規則は別途仕様化した時点で差し替える。
- 解決済みのマップモンスターレベルを `L` とする。編成の最大出現数 `M` は危険度が
  `high` なら5、`low` なら4とする。候補母集団は `lv == L` とし、危険度が `high` の場合だけ
  `lv == L + 1` かつ `early_appear == 1` も加える。同じモンスターキーは母集団へ重複追加しない。
- `allow_demons == false` では `DEMON`、`allow_humans == false` では `HUMAN` と `MAGE`、
  `allow_giants == false` では `GIANT` を候補から外す。`allow_large_animals == false` では
  `large_animal == 1` を候補から外し、`true` では通常候補と同じ条件で含める。
- `UNDEAD` または `GOBLIN` のモンスターを編成へ加えた後は、以後の母集団から `HUMAN` と
  `MAGE` を除く。逆に `HUMAN` または `MAGE` を編成へ加えた後は、以後の母集団から
  `UNDEAD` と `GOBLIN` を除く。これらの組み合わせを同じ敵パーティへ混在させない。
- 傾向が `yang` なら `weakness` に `炎` を含む候補、`yin` なら `冷` を含む候補を外す。
  `neutral` では両者を候補に残すが、炎または冷弱点を持つ各候補の抽選重みを通常候補の
  1/2とする。両方の弱点を持つ候補も重みは1/2とする。
- 母集団から1種類を重み付き抽選し、1〜`max_occ` 体を編成へ加える。危険度が `low` の場合、
  `max_occ` は1/2の小数切り上げとする。追加後の総数が `M` を超える場合はそのグループを
  加えず編成を終了する。
- グループ追加後、`M - 現在の総出現数` が1〜`M`の乱数より小さければ編成を終了する。
  継続する場合は1/2の確率で `L` を1下げ（最低1）、新しい `L` で母集団の作成から繰り返す。
  2グループ目以降の母集団からは、その戦闘の編成にすでに加えたモンスターキーを除く。
  同じモンスターを再抽選せず、1種類の出現数は1回分の `max_occ` を超えない。
  前衛・後衛はグループ境界ではなく、戦闘画面の表示スロットから決定する。
- 初回の母集団が空になる設定は編成データ不正として扱う。2グループ目以降で母集団が空に
  なった場合は、そこまでの編成で終了する。
- DA1にあるドアを開けた際の個別抽選は実装しない。
- この経路から生成する戦闘だけ不意打ち抽選を有効にする。抽選式、スキル「けいかい」、
  成立後の隊列と手番処理は [`battle.md`](./battle.md) の「不意打ち」に従う。

## デバッグエンカウント

- デバッグメニュー先頭の「エンカウント」を選ぶと設定画面を開く。現在マップのprofileや
  エンカウント設定にかかわらず、指定した条件で通常のランダム編成を生成できる。
- 編成の設定項目と選択肢はマップエディタと共通とし、フロアのエンカウント有無は扱わない。
  モンスターレベルは1〜9／変動、危険度は
  低／高、傾向は陽／中立／陰、悪魔・人間・巨人・大型動物出現はそれぞれあり／なし。
  変動のレベル解決と候補抽出は通常の `EncounterSystem` を使う。
- 起動時の初期値はレベル1、危険度低、傾向中立、悪魔・人間・巨人なし、大型動物あり。
  設定変更は即時にメモリへ保持し、キャンセル、戦闘終了、デバッグメニューの閉じ直しを
  経ても次回同じ値を表示する。Gameが起動中の専用状態を所有し、SaveDataやSettingsには保存しない。
- 設定Windowはデバッグメニューと同じ `(2, 2, 60, 56)` の4pxグリッドとし、各設定の相対Yを
  12〜30の3刻み、ラベルXを6、値Xを40とする。先頭の「バトル開始」はY=9、変更ガイドはY=45、
  戻るガイドはY=49。上下入力で行選択、左右または決定で値を循環変更する。
  デバッグメニューを開いたときは「エンカウント」、設定画面を開いたときは「バトル開始」を選択する。
- キャンセルでは「エンカウント」を選択したデバッグメインへ戻る。「バトル開始」の決定で
  編成を先に検証し、候補がなければエラー通知して設定画面に留まる。
- 開始成功時は編集中のパーティを反映し、デバッグと設定画面を閉じ、通常の遭遇演出と
  不意打ち抽選を伴うBattleSceneへ進む。歩行用のエンカウント変数は変更しない。
  勝利・逃走・全滅後は通常の戦闘復帰処理でフィールドへ戻り、報酬・成長・戦闘回数も通常どおり扱う。

## 戦闘開始演出

- エンカウント成立時にフィールド移動を停止し、現在マップのBGMが再生中ならその秒位置を退避してから、
  BGM ID `da3-encount` をループなしで再生する。通常・イベント・デバッグ戦闘で共通とする。
- 成立時点のフィールド画面全体を1回だけ画像へ保存する。拡大開始と同時にPCを非表示とし、
  保存対象にはPCを除いたマップ、actor、宝箱、前景を含む。
- 非表示前のPCスプライト中心を拡大中心とし、保存画面を最初の32フレームで1倍から4倍へ
  加速的に拡大する。残りの8フレームは4倍を維持する。
- 開始直後から時計回りに回転し、最初はゆっくり、後のフレームほど回転速度を上げながら
  最終的に2回転する。同時に32フレームかけてゆっくりホワイトアウトし、最後の8フレームで
  白から黒へフェードアウトする。
  40フレームは現在の `da3-encount` の長さに合わせる。
- 完全暗転時に本編の `BattleScene` を生成する。戦闘Scene自身の開始フェードインへ連続させ、
  フィールド画像を再描画しない。

## 戦闘終了とフィールド復帰

- 最後の敵の死亡演出が完了したら勝利メッセージと成長リザルトを順に表示し、2画面目を決定入力で閉じた時点で `BattleResult.VICTORY` を確定する。
- 初回の戦闘突入、成長リザルト表示、全滅復帰では、設定が有効な場合に対応するゲーム内ヒントを
  1回だけ表示する。表示タイミングと保存フラグは [`game-hints.md`](./game-hints.md) を正本とする。
- 勝利時は完了済み戦闘回数を1増やす。逃走と全滅では増やさない。
- 勝利は戦闘画面を標準6フレームでフェードアウトし、完全暗転時にフィールドへ
  切り替えて6フレームでフェードインする。全滅は完全暗転後、黒背景上に顔画像
  `(0, 224)` と `defeat.return.message` を標準メッセージOverlayで表示する。最終ページの
  確認後、フィールドへ切り替えるのと同時にテレポート音（SE 8）を再生する。完全暗転を
  維持したままSEの終了を待ち、その後6フレームでフェードインする。
- 逃走とフェードはBattleScene内の暗転後、熟練度または最大MPが増えた場合だけ成長リザルトを
  表示する。リザルトを表示した場合は閉じた後に標準6フレームで暗転する。成長がなくリザルトを
  省略した場合は暗転状態を維持し、どちらもフィールドへ切り替えて6フレームでフェードインする。
- 勝利・逃走・フェード後は、戦闘開始前に退避した位置から現在マップのBGMをループ再生する。
  戦闘中の時間をフィールドBGMの位置へ加算しない。退避できなかった場合は先頭から再生する。
  勝利・レベルアップジングル後の復帰にも同じ位置を使い、ジングルを切り替えても退避位置を保持する。
  逃走・フェード後に成長リザルトを表示する場合は、そのフェードイン開始時から再開する。
  リザルト中にフィールドBGMが再開済みなら、追加のジングルはその時点の位置を退避し、
  フィールド切り替え時には再スタートせず継続する。全滅復帰では復帰先マップのBGMを先頭から再生する。
- 勝利・逃走・フェード後のフィールド復帰は画面だけをフェードさせ、BGMの音量は維持する。
  継続中のフィールドBGMやレベルアップジングルを画面の暗転に合わせて減音せず、
  リザルトを省略して暗転中にフィールドBGMを再開する場合も、最初から設定音量で再生する。
- ダンジョン歩行による全滅では、復帰確定時に継続中のフィールドBGMを停止する。テレポート音
  （SE 8）の終了後、フェードイン開始と同時に現在マップのBGMを先頭からループ再生する。
- 睡眠、混乱、スタン、防御・素早さ補正は戦闘限定状態としてフィールドへの切り替え時に解除する。
  勝利と逃走では毒と麻痺を解除せず、元のフィールドへ持ち越す。
- 勝利と逃走ではエンカウントしたセルと向きを維持する。
- 全滅では、フロアの `area_parent_id` があれば親ダンジョンのマップへ戻る。旧生成データは
  `<親マップID>_area_<フロアID>` の名前から親を解決する。親がなければ現在マップを使う。
  復帰先マップの `sites` のうち、dungeon以外のマップへ出る移動口だけをダンジョン出口として
  選び、フロア間の階段・移動口は候補にしない。出口が複数ある場合は現在位置との距離で選ぶ。
  その出口セルを直接踏まない隣接通行可能セルへ移動し、出口を向く。隣接セルは階段を含む
  すべての移動口を避ける。マップが変わる場合は描画・actor・拠点索引・BGMも復帰先へ切り替え、
  元フロアのFADE効果を解除する。
  複数候補の距離が同じ場合は安定IDと座標で決定し、再現可能にする。
- 全滅では暗転後のメッセージを確認して入口へ戻す際に、現在パーティ全員のHP・MPを最大値へ
  戻し、すべての状態異常と戦闘中補正を解除する。使用可能な出口がない不正なマップでも
  全回復は行い、現在マップと位置を維持する。親マップが読み込めない場合も同様とする。

## セーブ互換

書き出すv1セーブの `progress.encounter_count` は必須とする。この項目を追加する前に作られた
既存のv1セーブだけは0として復元し、次回保存時に項目を追加する。戦闘開始演出、戦闘中、
戦闘終了フェード中は従来どおり保存できない。

## 受け入れ条件

- dungeon profileの完了歩行だけがエンカウント変数を1〜4増やし、120以上でマップ設定に
  応じて生成した1〜5体の編成との戦闘を開始する。
- 2グループ目以降では編成済みのモンスターを再抽選せず、各種類の出現数が適用後の
  `max_occ` を超えない。未選択の候補がなくなれば、その時点の編成で終了する。
- フィールドでFADEを使うと、そのマップにいる間だけ現在値を維持したまま発生ボーダーを
  240へ変更し、戦闘復帰では維持、マップ移動では解除できる。
- 通常ランダムエンカウントから開始した戦闘だけが不意打ちを抽選する。
- エンカウント変数を保存・復元でき、旧v1セーブは0として復元できる。
- PCを中心にフィールド全体を加速的に拡大・2回転させながらホワイトアウトし、最後に暗転して
  戦闘を表示する。回転は開始直後から徐々に加速する。
- 最後の敵を倒す、逃走する、全滅する各結果からフェードを介してフィールドへ復帰する。
- 勝利・逃走・フェード後にフィールドBGMが戦闘開始前の続きから再開し、勝利からレベルアップへの
  ジングル切り替えとリザルトからフィールドへの切り替えでも位置を失わない。
- リザルトからフィールドへの画面フェード中もBGMの音量を維持し、短い減音・増音を挟まない。
- 勝利と逃走では毒と麻痺を元のフィールドへ持ち越し、全滅ではHP・MPとともに全回復する。
- 全滅時は完全暗転後に指定の顔画像と4行の復帰メッセージを2ページで表示し、確認後に
  ダンジョン自体の入口があるマップの出口直前へ移動して出口を向き、フロアの階段には戻らない。
