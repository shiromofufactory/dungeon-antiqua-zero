# 情報メニュー・会話ログ・モンスター図鑑

## 目的

メインメニューの `menu.command.info` から情報サブメニューを開き、現在のセーブデータへ
保存された会話ログと、登録されたモンスター情報をDA2と同じ操作で確認できるようにする。

図鑑の開示状態と戦闘中の記録条件は [`save-data.md`](./save-data.md) と
[`battle.md`](./battle.md) を正本とする。この画面は `monster_records` へ保存された安定キーを
`monsters.json` の現在値へ照合して表示するだけで、マスターデータをセーブへ複製しない。

## 画面遷移

```text
メインメニュー「じょうほう」
  → 情報サブメニュー
      ├─ 会話ログを決定 → 会話ログ選択
      │                    └─ キャンセル → 情報サブメニュー
      ├─ モンスター図鑑を決定 → モンスター図鑑
      │           └─ キャンセル → 情報サブメニュー
      └─ キャンセル → メインメニュー
```

- メインメニューとの往復には標準フェードを使う。
- 情報サブメニューとモンスター図鑑の往復ではフェードしない。
- 情報サブメニューと会話ログ選択の往復ではフェードしない。
- 表示可能なログが0件の状態で `information.conversation_log` を決定した場合は、共通エラー音と
  画面揺れを発生させ、情報サブメニューに留まる。
- 図鑑登録が0件の状態で `information.monster_book` を決定した場合は、DA2と同じ共通エラー音と
  画面揺れを発生させ、情報サブメニューに留まる。
- 各画面から情報サブメニューへ戻った時は、選択中カテゴリのカーソルを再びactiveにする。

## 情報サブメニュー

画面座標は4×4pxグリッドで表す。

| Window | 座標・寸法 | 内容 |
|---|---:|---|
| カテゴリ | `(0, 0, 32, 15)` | 上から `information.conversation_log`、`information.monster_book` とカーソル |
| 本文 | `(0, 15, 64, 45)` | 会話ログ選択中はログ一覧。モンスター図鑑選択中は空欄 |

上下入力でカテゴリを循環し、同じフレームで本文を更新する。将来カテゴリを追加する余地は
残すが、未実装カテゴリをdisabled項目として表示しない。

## 会話ログ

`SaveData.logs` を保存順（新しいものから古いもの）で表示する。各ログは青色の `現在番号/総数`、
1行以上の本文、空行の順に並べる。カテゴリを選択している時点で本文へ一覧を表示し、決定すると
本文側のカーソルをactiveにする。上下入力は前後のログ見出しへ移動し、先頭と末尾で循環する。
表示領域を超える場合は、選択ログの見出しだけでなく本文末尾まで見える位置へ縦スクロールする。
1件のログ自体が表示可能行数を超えない限り、選択したログの本文を途中で見切れさせない。
キャンセルはカテゴリ選択へ戻り、さらにキャンセルするとメインメニューへ戻る。

ログは保存済みの `text_key` または `message_id` と `arguments` を使い、画面を開いた時点の
Settingsと言語で `TextCatalog` または `EventMessageCatalog` から再解決する。削除済みのキーなど、
現在言語で本文を解決できないログは表示対象から除外する。保存順と上限、およびログの保存形式は
[`save-data.md`](./save-data.md) を正本とする。

会話本文には漢字を含むため、日本語では通常メッセージWindowと同じ `FontRole.LARGE`
（`umplus_j12r.bdf`）を使い、4グリッド（16px）間隔で配置する。英語は同じ意味役割の英語フォントを
使い、3グリッド（12px）間隔とする。簡体字中国語は4グリッド間隔とする。見出しと空行を含む
ログ一覧全体を同じ行送りで扱う。ただし `現在番号/総数` の見出しだけは言語設定に関係なく
日本語標準の8×12フォント（`k8x12S.bdf`）を使い、数字と記号を「１／３」のように全角表示する。

## モンスター図鑑

### レイアウト

| Window | 座標・寸法 | 内容 |
|---|---:|---|
| カテゴリ | `(0, 0, 32, 15)` | 情報サブメニューの非activeカーソルを維持 |
| 一覧 | `(0, 15, 32, 45)` | 遭遇済みモンスターを14件ずつ表示 |
| 詳細 | `(30, 0, 34, 60)` | 選択モンスターの図鑑情報と画像 |

一覧は `monsters.json` の配列順で並べる。表示No.はこの配列順を1始まりにした値とする。
表示名やNo.を保存識別子には使わない。ゲームクリア状態が未実装の間は、未遭遇モンスターを
「？」として補完せず、`monster_records` にキーがある遭遇済みモンスターだけを表示する。
マスターから削除された未知の保存キーは一覧に表示しない。

上下入力は前後のモンスターへ移動し、先頭と末尾で循環する。前後ページ入力は14件単位で移動し、
端のページから反対端へ循環する。選択変更と同じフレームで右側の詳細と画像を更新する。

### 詳細の開示段階

遭遇済みであれば、開示項目が空でも次を表示する。

- 図鑑No.
- 現在言語のモンスター名
- `term.monster_tribe.*` から解決した種族名
- `monsters.json.lv` の実際のモンスターレベル
- HPとMPの `？？？？`
- `monster_book.unidentified`

`profile` と全 `ResistanceType` が `revealed_field_keys` に揃った場合を完全識別とする。
`treasure_identified` と `treasure_acquired` は完全識別の判定へ含めない。完全識別後は
次を追加または開示する。

- 全モンスターの最大HPと最大MP
- 耐性と弱点のアイコン列。該当属性は通常アイコン、非該当属性はdisabledアイコンにする。
  DA2の9属性にないZEROの `STUN` は表示しない。
- `treasure_identified` または `treasure_acquired` がある場合は `treasure_item` が参照する
  現在言語のアイテム名、どちらもない場合は
  `monster_book.treasure_unknown`

LVはHPの直前へ置き、値をHP・MPと同じ数値欄へ右揃えする。「おたから」「たいせい」
「じゃくてん」は開示状態や内容にかかわらず通常色で表示する。

ボスを含め、完全識別後は最大HPを実値で表示する。

画像は `image_id` の `monsters/{image_id}` を使い、詳細Window内のDA2相当位置へ原寸表示する。
表示名や一覧順から画像を推測しない。

## 表示文言

実際の文言は `content/data/texts.json` の次のキーを正本とする。

- `information.monster_book`
- `information.conversation_log`
- `monster_book.number`
- `monster_book.hp`
- `monster_book.mp`
- `monster_book.level`
- `monster_book.treasure`
- `monster_book.treasure_unknown`
- `monster_book.tolerance`
- `monster_book.weakness`
- `monster_book.unidentified`
- `term.monster_tribe.*`

## 受け入れ条件

- メインメニューの「じょうほう」を決定すると情報サブメニューが開く。
- 会話ログは新しい順に表示され、上下でログ単位に循環し、長い一覧では選択位置へスクロールする。
- 日本語の会話ログはイベントメッセージと同じフォントで表示される。
- 会話ログはロード後も現在言語で再解決され、保存済み引数を本文へ反映する。
- 情報サブメニューからモンスター図鑑を開き、キャンセルで情報サブメニュー、さらにキャンセルで
  メインメニューへ戻れる。
- 一覧に遭遇済みモンスターだけがマスター順で表示され、No.は未遭遇分を詰めない。
- 不完全記録でもLVは実値を表示し、HP・MP・お宝・相性は開示しない。
- 完全識別後はボスを含めて最大HPを表示する。
- お宝名はアイテム図鑑ではなく、そのモンスターの `treasure_identified` または
  `treasure_acquired` で開示される。
- セーブ・ロード後も同じ一覧と開示段階が復元される。
