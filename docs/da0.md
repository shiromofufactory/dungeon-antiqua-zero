# 登場人物

- 長老:  
  da2のラストで空間崩壊に飲まれてda0以前の世界にきた ようせい
  ほぼ精神体 予言者(当然) 空間崩壊と加齢の影響でだいぶ記憶があやしいが、何が起きるか 起きたかは知っている
  ZERO開始の数年前に里に現れたので土着ではないが、あまりにも高い魔力を放つため長老として崇められている
- フィオラ（Fiora）:  
  妹ようせい＝主人公。最初は激弱だが成長が著しい。黄色い花が好き。どちらかというと攻撃系呪文メイン、得意武器は弓矢か小剣・短刀。
- セリオン（Cerion）:  
  兄ようせい＝準主人公。穏やかな性格で戦いは苦手。最終パーティに同行させることもできるが、待機させることもできる。回復系呪文メイン、得意武器は槍。
- アルヴァン（Alvan）:
  パパようせい。大工。ドラクエ5のパパスのごとく、最初からめっちゃ強い。ちゃらけている。物語の途中でヒュドラにやられて離脱。戦士系で得意武器は斧。
- ラグナ（Ragna）:
  最終的に古の武具を扱ってデーモンを倒す勇者。強くて傲慢。デーモンを倒した後栄誉を独り占めして武具たちに反発される。得意武器は剣。NPC（最終的に怒った武具に誅罰されるため。）
- エリカ（Elika）:
  人間。女侍、猪突猛進。（仮）デーモンに襲撃された村の孤児たちを守る。最終的に剣になる。得意武器は刀。NPC。
- ダイン（Dain）:
  ドラゴニュート。男パラディン。温厚で冷静沈着な人格者。古の武具プランに真っ先に賛同する。最終的に鎧になる。得意武器は斧。NPC。
- アルファード（Alphard）:
  ドワーフ。男僧侶、最終的に盾になる。
- クレス（Cress）:
  ハーフエルフ。女ビショップ、最終的に兜になる。古の武具プランを考えるひと。天才で変人。2のルーンの祖先。得意武器はワンド。NPC。
- バルトロメ（Bartholome）:  
  人間。男魔法使い。魔法大学の教授で闇魔法の研究者。最終的に小手になる。1のチュートリアルジジイ、2のチュートリアルジジイの祖先。
- エラン（Elan）：
  エルフの村の長。プレイヤーキャラクターではないがストーリ上それなりに存在感がある。
- アバドーン（Abaddon）:
  後のエンシェントデーモン(精神体)。初期はダメージを受けている。この世界にタイムリープしてから世界中の魔力を吸い上げだす。
  裏設定として、武具らに裏切られたラグナの怨念が大悪魔を作ったことにしたい。つまり大悪魔＝勇者、ただゲーム内で明確には明かせず、深読みすればそういうことだと読み解けるようにする。
- ヘルたち:  
  アバドーンの手下。
- エルディアス（Eldias）: 
  後のエルダードラゴン。この時代から竜の長老

# 世界設定

- アバドーンが転移してくるまでは世界に魔力が満ちている
- 魔力機構による高度な文明(FF6を想像してもらうとよい)
- (魔力で動く)転移システムがあちこちにある(から、フィールドの移動は最終段階までない)

# システム

## 魔力機構システム

フリーシナリオの都合と、アバドーンの設定にもとづき、

- 時間経過(仮:戦闘回数)に応じて
  - 敵/アバドーンが強化されていく
  - 町の魔力設備がダウンしていく→終盤は使えなくなっている
- 魔力吸収
  - ヒトはほぼ影響を受けない(ハーフは影響軽微)
  - 妖精は魔力存在なので大きく影響を受ける(老体は活動不能になる程度)
  - エルフは影響を受ける
  - 魔法の威力が減衰する
  - ドラゴンの試練(エルディアスの5人のこどもたち)を受けると影響がなくなる 試練の塔の元ネタ
  - プレイヤーの意欲を失わせないに「弱まるけど、修行によって克服できる（自分が強くなれば魔力弱体化以上に強化量が上回る）」という励ましのメッセージを序盤に。また特別な鍛錬で根本的に克服できる（＝ドラゴンの試練のほのめかし）も早めに。

## キャラクタと育成システム

### 基本

- パーティは6人まで、ただし戦闘参加は5名まで（ロマサガ3的）。フィオラ固定、セリオンは後半まで固定だが最終盤では外せる
- NPCはゲーム進行に応じて固定。最終的にはいなくなるので、フィオラ（＋セリオン）＋各地にいる自由枠の仲間3名となる
- NPCの装備ルール：装備は外せない、ただし空き枠に追加することはできる
- 転職・クラスチェンジはない。表中の職業（侍、パラディン）は便宜上の記載で、ゲーム内では表記しない予定
- 1にあった「ちからのみ」などで特定のキャラを強化できる。【仮】上限回数は5なので、基礎25+5=30が最大
- 武器種・呪文種ごとにレベル制。武器種レベルは命中率やダメージに影響、呪文レベルは上がるごとに新しい呪文を習得
- キャラクタレベルは主にHP, MPや耐久性能に影響（ダメージにも若干影響）

## バトルシステム

- ターンの頭に全員の行動指定ではなく、順番が回ってきたらコマンドを決めて即行動する方式。
- 行動順は素早さで決まるのと、装備品の重さや呪文ごとの設定値に応じて「行動後に発生するウエイト」があり、1人が1回行動する間に別の1人が2回行動することなどもある。
- 隊列の概念（前衛・後衛）があり、2のように自由指定できる。戦闘中も入れ替え可能なのと、前衛が全員倒れたら誰が前に出るかは指定できる。

- クロノ・トリガーのように移動可能なワールドマップがあるが、エンカウントはダンジョン内のみ
- ランダムエンカウント方式

# ワールドマップ

![ワールドマップのコンセプト](./pics/worldmap-concept.jpeg)

## 妖精エリア

- 妖精の里：スタート地点。ゲーム後半では襲撃後マップに変わる
- ネクターの森：チュートリアルミッション用
- ヒュドラの洞窟：妖精エリアとエルフエリアを結ぶ洞窟

## エルフエリア

- シルヴァリア：エルフ族の中心値。シルファ所在地
- リアンノル：すでに悪魔に襲撃されてほぼ壊滅しているが、わずかに残ったエルフたちが暮らしている。ライザ所在地
- 賢者の祠：クレスがここで魔法の研究をしている

## 人間エリア

- ローンウィック：大陸で最も繁栄している。バルトロメが魔法大学で魔法を教えている。ヴァレンスとの定期便が出ている。オルウェン所在地
- ハルウェル：街に大きな教会があり、信心深い人が多く住む。水に恵まれ風光明媚な街。ミリア所在地
- イザヨイの村：人間界の中でも独自の文化（現実性界でいう東アジア的な文化）を築いている。カゲトラ所在地。またカスミもここの出身
- 漆黒の森：背の高い木が密集しており森全体が常に暗いためこう呼ばれる。ハルウェルからここを通らないとイザヨイの村に行けない。カスミがいる
